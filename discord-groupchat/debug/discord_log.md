## 直近の会話（80件まで）
- **09/11 06:47 kohei**: .mdファイルってどんなファイル？
- **09/11 06:47 Orchestrator**: .md は Markdown（マークダウン）という書式で書かれたテキストファイルです。中身はただの文字で、特別なソフトはいらない。メモ帳でも開けます。

**特徴**
- 記号で見た目を指定する。`# 見出し`、`- 箇条書き`、`**太字**`、`[リンク](URL)` など。
- GitHub やクロードアプリ、Notion、Obsidian などが .md を読み込むと、その記号を解釈して見出しや太字に整形して表示してくれる。
- 記号を無視して素の文字として読んでも意味が通るように作られている。だから軽くて壊れにくい。

**よく使われる場所**
- GitHub の説明書（README.md）
- クロードアプリや Claude Code に渡す指示文（さっき書いていた「応答の好み」もこれで書いて貼れる）
- 開発メモ、ドキュメント全般

要するに「記号で軽く装飾できる、ただのテキストファイル」です。拡張子を .txt に変えても中身は読めます。
- **09/11 06:47 kohei**: ai使ってるとよく見る
- **09/11 06:48 Orchestrator**: そう、AIまわりは説明書きが全部 .md なんです。理由はいくつかあって：

- **文字だけで軽い**ので、AIに読み込ませても余計な情報が混じらない。Wordみたいに書式データを持たない。
- **見出し・箇条書き・コードのまとまりを記号だけで表せる**ので、AIが文章の構造（ここが見出し、ここが手順）を理解しやすい。
- GitHubやClaude、ChatGPTのプロジェクト機能など、開発系のツールがそのまま整形して表示してくれる。

だから「README.md」「指示文.md」「メモ.md」みたいな形で、AIに渡す前提のテキストはたいてい .md になっています。さっき書いてた応答の好みの文章も、.md で保存しておけば使い回しやすいです。
