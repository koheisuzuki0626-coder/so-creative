# A. プロの事例動画の演出（サムシングファン事例106本）

外付けHDD `元データ` の事例動画 **106本**（軽量版除く・合計6.9時間）を、
1本あたり代表5フレームを抜いて画を読み取って分析した（2026-08-30）。
読み取り：Gemini 2.5 Flash 26 / Flash-Lite 23 / Claude CLI 57。

## A-1. 全体の傾向（頻度集計）

| 観点 | 多い順（数字はフレーム言及数の目安） |
|---|---|
| **テロップ** | ほぼ全編で存在（469）。この事例群の最大の共通項。画面下部の帯＋キャッチ or 字幕が定型 |
| 被写体 | 人物 389 ／ 製品 196 ／ ロゴ 185 ／ 設備 80 ／ 建物 66 ／ 風景 58 |
| 屋内 / 屋外 | 屋内 380 ＞ 屋外 312（インタビュー・工場内・会議室が多い） |
| 画角 | 寄り 287 ＞ 引き 144（バストアップ中心。全身・空間見せは補助） |
| カメラワーク | **フィックス 276** ＞＞ パン 65 ＞ ズーム 56 ＞ 手持ち 53（三脚固定が基本。動かすのはアクセント） |
| 構図 | 三分割 68 ／ 日の丸 61 ／ 対称 58（三分割がやや優勢。余白を残す） |
| 色調 | 暖色 127 ＞ 寒色 84（全体に暖色寄り・均一ライティング・明るめ。ハイコントラストは稀） |
| 空撮 | 101（ドローンは9）。導入や締めで規模感を出す「差し画」として使う |
| CG・グラフィック | CG 61 ／ モーショングラフィック 36（実写88と混在。UI・図解・数字パネルを重ねる） |
| 語り | ナレーション 47 ／ インタビュー 43 |

**要するに：** 三脚固定・寄り中心・テロップ常時・暖色・屋内。
「読ませて理解させる」情報伝達型が土台で、空撮とモーショングラフィックスで
スケール感と要点整理を足している。手持ちのライブ感や攻めた色設計は少数派。

## A-2. 冒頭3秒の入り方（実例パターン）

| 入り方 | 使っている事例 | ねらい |
|---|---|---|
| **空撮 → 引き → 寄り** の順で寄っていく | 新通コム万博（デンマークをドローンで）／製造業展示会ガリレイ | 規模感を先に見せて「大きい話」だと分からせる |
| **年号の大テロップ＋当時の白黒写真をコラージュ** | MIZUNO歴史（"1957"）／クラウン70th（"1921"） | 歴史・信頼を一発で提示 |
| **ロゴのフェードイン＋概要テロップ** | パナソニックAWE／キンコーズ ONDEMAND MPM | サービス名を先に刷り込む |
| **葛藤の画（頭を抱える／暗い）から入る** | 日本イーライリリー オープニング（革靴の寄り→頭を抱える人物→逆光） | 感情ストーリー型。「課題」を体で見せてから解決へ |

→ **人物アップ始まりは少数派**。まず「何の話か」を画で提示してから人に寄る。

## A-3. カメラの動かし方（動かすのは意味がある時だけ）

- **基本は三脚フィックス**（276カット）。情報を読ませる場面は必ず止める。
- 動かす時の定番：
  - **スライダー or 微速ズームの"寄り"**＋浅い被写界深度＝「じっくり見せたい主役」
    （天領サイネージ、灯り系プロダクトムービー、施設紹介）
  - **歩行フォロー（後ろから前進ドリー）**＝「体験を追う」ライフスタイル系
    （ライオンハート施設紹介、大学キャンパスツアー）
  - **ローアングルの煽り＋ティルトアップ**＝スケール・荘厳さ（鳥居→滝、建屋の骨組み）
  - **空撮は水平を保った俯瞰**、構造物を画面中央〜やや下に置いて安定させる
- **手持ちは現場・作業風景の"ライブ感"限定**（48カット、多くはインタビューの職場カット）。

## A-4. テロップの出し方（この層の生命線・全編で使用）

- **下部の帯＋キャッチ**が定型。1画面＝1メッセージ。
- **数字は大きく単独で**：「No.1」「最短で3分の1に短縮！」「着工棟数 No.1」。
  項目インデックスに大きな数字（1 / 5 / 7）を振るのも定番。
- **吹き出し＋擬音**でコミカルに（ユニ・チャーム グラン・デリ＝漫画のコマ割り演出）。
- **斜めの分割線**で画面を割り、左に写真／右に数字・テロップ＝動きのある情報画面。
- **ト書き風の状況テロップ**（「厳かに」等）で世界観を切り替える。

## A-5. 実写がない／弱いカットの埋め方（AI制作で効く）

- **機能アニメーション**：製品の断面・動作をイラストで（ニプロ Surdial、エクセディ、
  興亜工業の溶解処理）。
- **ホワイトボード／線画ドローイングアニメ**：理念・仕組みを手描き風で（共栄セキュリティ、
  アストラゼネカ系Eラーニング）。親しみやすさ＝硬い話を軟らかく。
- **UI／スペック表を全画面パネルで**：1画面1トピック、前後で状態を変えて違いを見せる
  （ニプロ Max-Subモード、SEMICON 製品ラインナップ）。
- **地図＋写真の年代順タイムライン**：沿革・実績の一覧化（MIZUNO、天領の全国展開）。
- **多分割画面（2〜4分割）＋透過エフェクトで次シーンへ**：実績・拠点を密度高く見せる
  （大阪大学 海外拠点紹介）。

## A-6. 色とライティングの型

- **信頼感＝暖色・均一ライティング・中コントラスト・明るめ**（企業紹介の大多数）。
- **感情・ブランディング狙いだけ寒暖の対比を強く使う**：
  「青（葛藤）→赤／オレンジ（希望）」の色ストーリー＋シネスコ（上下黒帯）＋
  英語スローガンで締める（日本イーライリリー、リーダー系ブランドムービー）。
- **情緒・雰囲気売り**：暗がりに暖色の灯りだけ主役、浅い被写界深度、前ボケ、
  微速の寄り、詩的コピー最小限（灯り系プロダクトムービー）。
- **夕景の逆光シルエット**は「余韻・締め」で1カットだけ効かせる。

## A-7. 締め方

- **主要メッセージを画面中央の大テロップで**（興亜工業＝「機密」の一語）。
- **人物の全員集合カット＋日本語コピー**で高揚（名古屋デモリール、スポーツPV）。
- **現場で働く人の姿**で信頼を残す（工場工程動画）。
- **「◯◯で検索」の検索窓を大きく**＝行動導線に落とす（アイニコ シネアド）。
- 英語スローガン（"Be a Leader" 等）＝事例より理念・ブランディング寄りに振る時。

## A-8. 構成の型（8種）

1. **説明・情報伝達型**（最多）— 課題提起 → イラスト／UIデモ → 効果、をテロップで整理。
   例：北陽電機チラシ動画、インナー向けAIサービス、興亜工業、キンコーズ、パナソニックAWE。
   1〜3分・短カット・アニメ多用。
2. **社員インタビュー・採用型** — バストアップのフィックス＋三分割、職場の引き画を挟む、
   テロップで属性表示。例：UBEマシナリー、リライフ、ライオンハート、阪和興業。
3. **対談型**（アストラゼネカ／シーズ系に集中・6本前後）— 2ショットの対称構図 → 個々の寄り、
   紫帯テロップ。会議室の均一ライティング。
4. **ヒストリー／周年型** — 年号の大テロップ＋当時の写真をコラージュ、時系列で送る。
   例：MIZUNO歴史、クラウン70th、なんつね100周年。
5. **製品紹介・展示会型** — 製品クローズアップ＋機能アニメ＋スペック表パネル。1画面1トピック。
   例：ニプロ Surdial、ダイヘン ロボットアーム、ホシザキ HCJ、SEMICON。
6. **線画・ホワイトボードアニメ型** — シンプルなドローイングで理念・仕組みを図解。
   例：共栄セキュリティ TVCM、アストラゼネカ系Eラーニング。
7. **検索CTA型**（短尺シネアド）— 最後に「◯◯で検索」を大きく出して行動導線に。例：アイニコ。
8. **抽象イメージ → 自社訴求型** — 風景・建造物の引き画や空撮から入り、後半で事業内容へ接続。
   例：新通コム 万博サイネージ、製造業展示会ガリレイ。

## A-9. 絵コンテ時のチェックリスト

- [ ] 冒頭3秒は「何の話か」を画で提示したか（人アップ始まりを避ける）
- [ ] 読ませるカットは止めたか。動かすなら理由を1語で言えるか
- [ ] テロップは1画面1メッセージ／数字は大きく単独か
- [ ] 実写が弱いカットをアニメ・UI・地図タイムラインで置き換えられないか
- [ ] 色は「信頼＝暖色均一」か「感情＝寒暖対比＋シネスコ」か、狙いを決めたか
- [ ] 締めは大テロップ／全員集合／働く姿／検索窓 のどれか

## D-4. この解析で分かったことの使い道

**効くもの**
1. **AI動画生成のプロンプト設計**。「フィックス・寄り・暖色・屋内・下部テロップ」という自分の型を
   そのまま英語プロンプトに落とせる。作風がブレる問題への直接の対策になる
2. **営業・提案の根拠**。「30秒尺中心、フィックス主体、暖色寄り」を1万本の実績で裏付けて言える
3. **自分の癖の発見**。AECrop 17,909回＝撮影時点で構図を決めきらず編集で直している可能性

**効かないもの（期待しない）**
- これは分析データであって学習データではない。AIが作風を再現できるようになるわけではない
- 個々の作品の良し悪し・クライアントの反応・成果は入っていない。傾向の集計に留まる

## D-5. 「完成CM」と「素材」は別物（ここが一番の発見）

そのまま作風だと思ってはいけない（実際に一度そう報告して訂正した）。
`tools/pick_finished_videos.py` でプロ品質の完成映像 **1,274本** を選り分け、
残り8,074本（素材・ラッシュ）と比べたら、はっきり差が出た。

|---|---|---|---|
| **製品** | **100.5** | 27.6 | **3.6倍** |
| **ロゴ** | **40.3** | 10.3 | **3.9倍** |
| **テロップ** | **53.8** | 29.2 | 1.8倍 |
| テロップ無し | 5.4 | 26.0 | 1/5 |
| 暖色 | 24.3 | 15.3 | 1.6倍 |

- **インタビューは撮るがCMには使わない**（0.6 対 3.2）

## D-6. AIっぽさを消す3つ（実測の裏付けつき）

AI動画生成が「作り物」に見える原因は、データと突き合わせると具体的に分かる。

| やること | 根拠 |
|---|---|
| **1秒前後のカットを畳みかける**。長回しにしない | 下のD-6-1が実測。AI生成は5〜10秒の連続ショットを出すので、1本の長回しはそれだけでAI製と分かる |
| **`locked-off camera, static tripod` と明示する** | プロの実作はフィックス36.4に対し手持ち4.3・パン6.3・ズーム4.4。AIは放っておくとカメラが漂う |
| **左右対称を避ける。中心を外して片側に余白** | **プロの実作で対称はわずか3.6**（三分割16.2／日の丸15.8）。AIは対称構図を好むので明示的に外す |

### D-6-1. カットの長さの実測（EDL 77本・1,996カット）

EDLのタイムコードから1カットの尺を計算した（`parse_edl` の `cut_secs`）。
イベント10件以上の「タイムラインEDL」77本だけを対象にしている
（残りはVFX用の1イベントEDLやプルリストで、編集のリズムを表さない）。

| カットの長さ | 本数 | 割合 |
|---|---|---|
| **1秒未満** | 1,062 | **53.2%** |

### 6. AIで作れるもの・作れないもの

9月下旬のリサーチは、毎回この切り分けを記録している。事業に直結するのでそのまま残す。

#### 作れる

| 対象 | 手順 |
|---|---|
| 工場・オフィス・測量現場などの**汎用背景** | プロンプトのみで生成。テロップは編集ソフト側で別レイヤー |
| **手元アップ**（書字・機械操作・PC作業・調理・演奏） | 2〜5秒の短尺で個別生成。正面顔を使わないので一貫性の崩れが露出しない |
| **単色背景＋ロゴのフェード冒頭カット** | 静止画生成 → ロゴ合成 → 動画AIに「ズーム/パン無し」を指定、BGMのみ |
| **機械・製品のクローズアップ群** | Kling/Seedance で5秒ずつ生成し、編集で2.2〜3.3秒に間引く |
| **製品の水平パン** | 実物商品写真を基準画像に、カメラを右→左へゆっくり動かす5秒動画（谷川屋型） |
| **1枚絵の疑似回転** | Image-to-3D で立体化 → 8方向レンダリング → 繋ぐ（ポプルス85秒相当） |
| **フラット2Dイラストの人物** | スタイル／シード固定で複数生成 → 「頷く」「腕を上げる」等の簡易動作を付けて3秒カット |
| **アニメ・イラスト調の人物** | 写実調より顔の微細なブレが目立たない（池袋学園型）。様式内なので許容される |
| **抽象モーション背景**（歯車・波形・パーティクル） | パーツを静止画生成 → 回転のみ指示 |
| **脇役として入れ替わる人物** | 顔の一貫性が不要な人物を個別生成 → ナレーション一文ごとに1カット割り当て |

#### 作れない

| 対象 | 理由 |
|---|---|
| **企業ロゴ・社名・看板の正確な文字** | 生成AIの文字レンダリングが不安定。実写撮影か後合成が必須（ITOCHU、ニッコー、ガイア、栄商事、lumielune で繰り返し確認） |
| **実在メーカーの精密機械の実機** | 外観・パーツ配置が図面通りでないと成立しない（DORNIER社・BROETJE社） |
| **設計図・仕様図面** | 図面らしい絵は作れても、意味を持つ寸法・仕様データは入らない（クラフトアール） |
| **Webサイト・ソフトウェアの実画面** | 実在サービスのUIではなく空想のUIを作ってしまう。画面録画が必須 |
| **QRコード** | 見た目が似た模様は作れても、実際に読み取れる配列は再現できない（機能要件） |
| **社長・社員インタビューの証言部** | 精度以前に「本人が実際に話した」という真正性そのものが価値。代替する意味がない |
| **20秒を超える連続ワンカット** | 生成AIの上限が数秒〜十数秒。一貫性以前に尺の制約（アイジー社28.3秒） |
| **対談の即興的な相槌・間** | 台本のない反応のタイミングは事前生成できない |
| **音声ミックスの緩急** | 内容の重要度に応じた動的な音量調整は出力対象外（大和証券） |
| **ナレーション尺に合わせた編集判断** | 生成した動画を後から音声に合わせて伸縮できない。人力で尺を詰める工程が必須 |

**まとめると、AIで置き換わるのは「絵の素材」だけで、「どの絵を何秒出すか」は丸ごと残る。**
これは値付けの根拠になる（工数が消えない理由の説明として使える）。

- **梅**：実写なし／キャラ一貫性が不要／人物は単カットのみ（顔の破綻リスクが低い）
- **竹**：テロップと音声の同期作業が要る／複数人物は出るがリップシンクは不要
- **松**：複数人物の顔一貫性が要る／ポーズ差し替え／実写合成

参考：伊藤忠型（225秒・68カット）を梅で受けると 78.75万＋基本料9万＝**約88万円**だが、
AIで作れるのは機械の寄りだけで大半が実写編集になるため、実際は松向き・工数30h超という評価だった。
**尺だけで階層を決めない。**

### 8. 両ジャンルに共通する4つ（MV側の分析と突き合わせた結果）

会社紹介動画とMVは見た目が全く違うのに、AI制作上の制約は同じ4つに集約される。

1. **AIの破綻はカット尺で隠す。** 1.5〜2秒に抑えれば顔や手足の崩れはほぼ見えない。
   逆に長く見せたいカットほど実写が要る
2. **顔を避ける構図が最大のコスト削減。** 後ろ姿・手元・シルエット・暗所・引きの群衆。
   「顔を映さない会社紹介」は実際に検証項目として挙がっている
3. **文字はAIに書かせない。** ロゴ・社名・看板・図面・QR・UI。すべて後合成。
   これは全期間で一度も例外が出ていない
4. **編集判断は代替できない。** 音に合わせる／尺を詰める／どの情報を何秒出すか。
   ここが人の工数として丸ごと残る

### 5. 演出の引き出し（8月の記録から、頻出順）

同じ技法が何度も繰り返し挙がっていたものを、出現頻度の高い順に並べた。

1. **ビートシンク** — 楽曲のキック・スネアに1フレーム単位でカットを同期。サビで加速。

2. **マッチカット** — カメラ位置を完全固定し、ポーズを揃えたまま衣装・背景だけ瞬時に切替。
   エフェクトに頼らず、追加ロケ無しでワープ感を出せる
3. **寄り引きの極端な緩急** — 顔の超クローズアップ（魚眼風の超広角）↔ ドローンの俯瞰。

4. **異物越しPOV** — グラスの底、コピー機の内側、窓枠、冷蔵庫の奥、車のバックミラー。
   普段見られない視点にカメラを置くだけで、低予算でもシネマティックになる
5. **環境音の楽器化（音ハメ）** — ストローを吸う音、足音、シャッター音、氷の音を
   ビートの一部として精密にミックスする
6. **マルチロケーション＋衣装替え** — 最低3〜5ロケ。数秒おきに視覚的な変化点を作る
7. **ロケごとのキーカラー固定** — 青＝海／緑＝庭／黄赤＝レトロ。色分けで世界観を分離する
8. **昼夜のライティング転換** — 同一ロケで自然光と夜の電飾を使い分け、
   ロケを増やさずに視覚バリエーションを2倍にする
9. **SNS UI の3D空間配置** — 通知・コメントを平面テロップでなく、映像内の奥行きに合わせて配置
10. **小道具起点のトランジション** — シャボン玉・マッチの炎・モップ・アイス・水滴・花びらを
    視線誘導のトリガーにして場面を繋ぐ
11. **静→動の落差** — 無音／静寂から一気に音を解放する。無音を1箇所だけ挟むと緊張感が際立つ
12. **色調を1本に絞る** — 単色グレーディングだけで、素材の質を超えて世界観の統一感が出る

### 7. AIで作れるもの・作れないもの

#### 作れる

| 対象 | 手順 |
|---|---|
| **背景単体**（車・自然風景・サイバーパンク都市・森・夜景・都市俯瞰） | プロンプトのみで生成 → 編集で切るだけ。またはカメラのみ微動する3〜5秒に |
| **顔が特定できない暗所のカット**（抱擁・水滴・手元クローズアップ） | 寄り構図＋逆光を指定。顔の一貫性を問われない |
| **同一人物 × 環境違い** | リファレンス画像で顔を固定し、各カット**5秒以下**で個別生成して繋ぐ |
| **単色背景＋ダンサー群像の後ろ姿** | 背面指定なら顔一貫性の破綻を問われず、コストが落ちる（米津玄師型） |
| **顔が判別できない引きの群衆・観客** | 2〜3秒で複数パターン生成し、実写メインカットの合間に差し込む |
| **非人物の象徴カット**（オーケストラ全景・電飾・小物） | 静止画生成 → 2〜3秒の微小カメラ移動 → ビートに合わせて差し込む |
| **抽象的な発光パーティクル・光の帯** | 静止画生成 → 浮遊・発光のみ指定。**ロゴ文字は入れない** |
| **マクロのオブジェ**（黄金の液体・ガラス片） | `golden liquid crystal shatter, dark background, macro` → `slow shimmer, subtle refraction, static camera` で3秒ループ |
| **スポーツの静止フォーム** | 構えの静止画を作り、動画AIに「カメラのみ動かす、被写体は静止」と指示 |
| **表情バリエーション** | 同一キャラのプロンプトで 怒り／悲しみ／驚き／笑顔 を複数生成し、カットごとに差し替え |
| **決めポーズのダンスカット** | 平均2.6秒という短尺の範囲なら、長尺の一貫性を要求されないので破綻しにくい |
| **黒背景＋白文字ロゴの冒頭カット** | 無地背景を静止画生成し、**文字はAIに書かせず後合成** |

#### 作れない

| 対象 | 理由 |
|---|---|
| **歌唱と同期した長尺のリップシンク・身体接触動作** | 関節位置がフレームを追うごとに崩れ、音ともズレる。実写かモーキャプが必須 |
| **実在アーティストの顔を保ったままの長尺ダンス** | 顔の同一性維持と関節の物理挙動を同時に保証できず、カットが長いほど破綻する |
| **1カットに9〜30人以上の密集構図** | 人数が増えるほど個体の位置・重なりの破綻率が上がる（きゃわぽっぴんどぅー9人、ヒロアカ30人以上） |
| **複数キャラが同一楽曲のリズムで同時に別々の演奏動作をする一貫性** | 被写体ごとに独立して動きを作るため、全員をテンポに同期させたまま保持できない |
| **衣装・ヘアメイクを2.6秒間隔で変えながら顔を全編一貫させる** | 参照画像を都度差し替える必要があり、生成のたびに顔がわずかにズレる |
| **同一セットの保持**（幾何学ステージ美術・スパンコール衣装） | カットごと独立生成なので照明・装飾の位置が毎回変わり、同一舞台の説得力が出ない |
| **ビート位置にミリ秒単位でカット点を合わせる編集判断** | 絵は生成できても、波形合わせは人力（サカナクション171カット・1.3秒） |
| **カメラが寄る速度・タイミングの制御** | 1カット内のパン・ズーム速度を狙って指定できない（なにわ男子 0:00-0:03） |
| **テロップがカット切替と完全同期する編集** | カット点の選択自体が演出判断なので自動化できない（M!LK のメンバー名テロップ） |
| **1カット10秒以上の身体接触ノーカット** | 抱き合う・絡むといった接触点の位置が動きと共にすぐ崩れる |

4. **編集判断は代替できない。** 音に合わせる／尺を詰める／どの情報を何秒出すか。
