# 先方のNDAを受け取ったときのチェックリスト

<img src="../ロゴ/logo-lockup.png" alt="so-creative" width="220">

**これはお客様に出す書類ではない。**署名する前に自分で確認するためのもの。

商談の段階で先方から秘密保持契約（NDA）を出されたときに使う。
**署名してしまってからでは直せない。**先に目を通すこと。

業務委託契約書の第8条（秘密保持）は「**本業務を通じて**知り得た情報」が対象なので、
**契約前の商談段階は守られていない。**そこを埋めるのが先方のNDA、という位置づけ。

---

## ⚠️ 最優先：AIに入れられるか

**ここだけは必ず見る。**他の項目は妥協できるが、ここは運用そのものが変わる。

いまの作り方は、**預かった資料をAIに入れる前提**になっている。

| | 何を入れるか | 学習への利用 |
|---|---|---|
| Claude | 構成案・ナレーション原稿のため、**資料を入れる** | オプトアウト済み（切ってある） |
| Higgsfield | **プロンプトだけ。**甲の素材は入れない | **オプトアウトできない**（規約2.3。消す以外に止める方法がない） |

### 見る文言

NDAにこういう条項があると、資料をAIに入れる行為が引っかかる。

```
「第三者に開示・提供してはならない」
「複製・改変してはならない」
「本目的以外に使用してはならない」
「外部のサービスに送信してはならない」
```

**クラウドのAIサービスに資料を送ることは「第三者への開示」に当たりうる。**
解釈の問題なので、黙って入れるのではなく**先に書面で合意しておく。**

### 書き加える文言（これを足してもらう）

```
乙は、本目的の遂行のため、秘密情報を外部のAIサービスに入力することがある。
この場合、乙は、入力した内容をAIの学習に利用しない設定が可能なサービスについては
当該設定を有効にして利用し、設定ができないサービスには秘密情報を入力しない。
甲が入力しないよう指定した情報は入力しない。
```

これは**業務委託契約書の第8条2項・3項・5項と同じ内容**。自社の契約書で
すでに使っている文言なので、そのまま持っていける。

### 書き加えられなかったら

**その案件は、資料をAIに入れずに進められるか**を考える。

```
入れなくても進む   ヒアリングの内容を自分で要約して構成案を書く
                  Higgsfield にはプロンプトしか渡さないので、そもそも影響なし

入れないと厳しい   資料が大量（社内報の過去号、長い議事録、仕様書）
                  → 工数が増えるぶんを見積りに反映するか、断る
```

**「入れないと決めたのに、うっかり入れる」が一番まずい。**
入れない案件は、資料の置き場をAIに読ませないフォルダに分けること。

## 次に見る3つ

### 1. 期間

| | |
|---|---|
| 守る期間 | 契約終了後 **3〜5年**が普通。**無期限は交渉する** |
| 情報の提供を受ける期間 | 「本NDA締結日から1年」などの定めがあるか |

自社の業務委託契約書は**3年**。それより長い期間を飲むなら、理由があるか確かめる。

### 2. 範囲

```
✅ 確認する   「秘密情報」の定義。何が秘密なのかが決まっているか
             → 「開示されたすべての情報」は広すぎる。秘密表示や
               書面での特定を求める形が普通

✅ 確認する   除外事由があるか（この5つは定型）
             ① すでに公知   ② 受領前から知っていた   ③ 第三者から適法に得た
             ④ 独自に開発した   ⑤ 法令・裁判所の命令で開示を求められた

⚠️ 注意      除外事由が1つも無いNDAは、守れない約束になる
```

### 3. 損害賠償

```
⚠️ 上限が無いNDAが多い。業務委託契約書の第10条2項は
   「委託料の額を上限」としているので、NDAだけ青天井だと意味が薄れる

交渉できるなら    「本件業務の対価の額を上限とする」を足してもらう
できない場合      そのリスクを飲める案件かどうかで判断する
```

**50万円の案件で、上限なしの賠償義務を負うのが妥当か**を毎回考える。

## そのほか、紛れていることがあるもの

| 項目 | 見る点 |
|---|---|
| **一方的か相互か** | こちらだけが義務を負う片務型か。**相互**にできないか |
| **返還・破棄** | 終了時に資料の返還や破棄を求められるか。**破棄証明書**まで要求されていないか |
| **再委託先への開示** | 業務委託契約書の第9条で再委託を認めている。NDAで禁止されていると矛盾する |
| **競業避止** | NDAに紛れて「同業他社の仕事を受けない」が入っていないか。**これは別物** |
| **成果物の権利** | NDAで権利の帰属まで決めていないか。業務委託契約書の第6条と食い違う |
| **管轄** | 遠方の裁判所が指定されていないか（争うときの移動費が効く） |
| **期限** | 署名の期限が切られていないか。急かされても読む時間は取る |

## 進め方

```
1. 受け取ったら、まず上の⚠️（AI）だけ見る
2. 引っかかる文言があれば、書き加える文言を提案する
   → 「普段このように運用しているので、1文足させてください」と伝える
3. 1〜3（期間・範囲・賠償）を見る
4. 迷ったら署名しない。1日持ち帰る
```

**先方の担当者も、法務から降りてきた定型文をそのまま回していることが多い。**
聞けば通ることがあるので、黙って飲まない。

**金額が大きい案件（30万超）や、相手が大手で修正に応じない場合は、
署名前に専門家に見てもらう。**知財総合支援窓口（無料）が使える。
