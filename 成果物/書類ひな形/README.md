# 書類のひな形

<img src="../ロゴ/logo-lockup.png" alt="so-creative" width="220">

**そのまま送る書類ではない。**これはGitHubで読むための版で、
お客様に出すのはPDF。送る前に体裁を整えること。

見積書・業務委託契約書・請求書。`〔〕` を埋めて使う。

## 3つに共通して入れてあるもの

ロードマップの P0「見積書・契約書・請求書のひな形。**著作権の帰属・段ごとの
修正回数・支払サイト**を書き込む」に対応している。

| | どこに | 中身 |
|---|---|---|
| 著作権の帰属 | 見積書「著作権」／契約書 第6条 | 支払完了をもって譲渡。用途・期間の制限なし。**AI生成物は保護が及ばない場合がある**ことも明記 |
| 段ごとの修正回数 | 見積書「仕様」／契約書 第4条 | 梅2・竹3・松3。超過は1回 ¥30,000 |
| 支払サイト | 見積書「お支払い条件」／契約書 第5条／請求書 | **着手金なし・全額を納品後**（2026-09-22 決定）。期日は**納品日から30日以内**が既定。相手の締め日に合わせる余地は残すが、**こちらから先に出す** |
| 消費税 | 見積書・請求書の金額欄／契約書 第5条 | **区分して請求しない。表示額がそのまま総額**（適格請求書発行事業者の登録をしていないため）。サイトの料金表示と同じ額になる |
| キャンセル | 見積書「着手後のキャンセル」／契約書 第5条3項 | 絵コンテ承認まで50%／生成着手後80%／初稿提出後100% |

## PDFの出し方（お客様に出すのはこれ）

```
cd ~/so-portfolio/discord-groupchat
venv/bin/python tools/make_doc.py 見積書 --to 株式会社ABC --title 会社紹介動画 \
    --tier 竹 --sec 60 --count 1 --nar ai
```

見積書・請求書・業務委託契約書の3つに対応しています。契約書だけ甲の住所と
代表者名も要ります。

```
venv/bin/python tools/make_doc.py 業務委託契約書 --to 株式会社ABC \
    --title 会社紹介動画 --tier 竹 --sec 60 --nar ai \
    --addr "愛知県名古屋市〇〇" --rep "代表取締役 〇〇 〇〇"
```

| 指定 | 意味 |
|---|---|
| `--tier` | 梅 / 竹 / 松 |
| `--sec` | 1本あたりの秒数 |
| `--count` | 本数 |
| `--nar` | `ai`（料金に含む）/ `human`（1名 +¥70,000。松は込み）/ `none`（1本 −¥25,000） |
| `--delivered` | 請求書のとき、納品日 |

**金額は式から計算されます。手で打つ欄はありません。**埋め忘れがあると
その場で止まります（空欄のまま出ない）。書き出し先は `_発行済み/`。

書式は `_書式/` の HTML と CSS。文言を変えるときはそちらを直します。

## 金額はサイトと同じ式で出す

```
料金 = 90,000 ＋ 秒単価 × 合計秒数 ＋ 65,000 ×(本数−1) ＋ ナレーション調整
秒単価 … 梅 3,500 ／ 竹 4,900 ／ 松 6,650
合計秒数 … 1本あたりの秒数 × 本数
```

**ナレーション調整**（ここが一番間違えやすい。2つが別勘定で、両方乗ることがある）

| | 人物 | AI | なし |
|---|---|---|---|
| 梅・竹 | **+70,000**（何本に入れても1名ぶん） | ±0（料金に含む） | −25,000 ×（入れない本数） |
| 松 | ±0（**秒単価に1名ぶんが溶けている**） | **−25,000**（手配1回ぶんを返す） | **−25,000** ＋ −25,000 ×（入れない本数） |

例：松・60秒・1本
人物 489,000 ／ AI 464,000 ／ なし 439,000。

見積書の数字とサイトの計算機が食い違うと、それだけで信用を落とす。
迷ったら https://koheisuzuki0626-coder.github.io/so-creative/pricing.html で確認する。

> **2026-09-24 に実際に起きた**：この README の式が古く（ナレーションを
> 「30,000 × 本数」と書いていた）、`make_doc.py` も松の AI／なしで
> −25,000 を引いていなかったため、**松の見積書がサイトより 25,000円 高く**
> 出ていた。いまは `test_routing.py` が 162通りすべてをサイトの式と
> 突き合わせている。**金額に関わる数字を手で打ち直さないこと。**

## 使い分け

| 規模 | 使うもの |
|---|---|
| 小口（〜30万） | 見積書 → 請求書。契約書は省き、見積書の「著作権」「追加費用」を承諾した旨をメールで残す |
| 大口（30万〜） | 見積書 → 業務委託契約書 → 請求書 |

> **2026-09-24 に見つかった**：ひな形が「小計（税別）＋消費税10%」で組まれていて、
> サイトが ¥384,000（税込）と出している案件を **¥422,400 で見積もる**形になっていた。
> 免税事業者なので消費税は区分して請求しない。**表示額がそのまま総額**に直した。
> ナレーションの行も「1本 ¥30,000」のまま残っていたので、上の式に合わせた。
