## 業務委託契約書

〔株式会社◯◯〕（以下「甲」という）と so-creative（鈴木 宏平、以下「乙」という）とは、
映像制作業務の委託について、次のとおり契約する。

### 第1条（目的）
甲は乙に対し、本契約に定める映像制作業務（以下「本業務」）を委託し、乙はこれを受託する。

### 第2条（本業務の内容）
1. 本業務の内容は次のとおりとする。

| | |
|---|---|
| 件名 | 〔会社紹介動画 制作一式〕 |
| 仕上げの段階 | 〔竹 上〕（登場人物2人まで） |
| 尺・本数 | 〔60秒〕・〔1〕本 |
| ナレーション | 〔AI〕 |
| 納品形式 | MP4（1920×1080 / 30fps / H.264 / 音声 AAC） |

2. 本業務には撮影を含まない。映像は生成AIを用いて制作する。

### 第3条（納期）
1. 乙は、甲の発注後 **〔2〕週間**を目安に納品する。
2. 構成案および絵コンテについて甲の確認を要する。**甲の確認が遅れた期間は納期に加算する。**
3. 第4条の編集チェックを行う場合、1回につき1週間程度を別途要する。

### 第4条（編集チェックと修正）
1. 乙は、仕上げの段階に応じて次の回数まで無償で修正に応じる。

| 仕上げの段階 | 無償の修正 |
|---|---|
| 梅 標準 | 2回 |
| 竹 上 | 3回 |
| 松 特上 | 3回 |

（**梅2回・竹3回・松3回**。サイトの料金ページと同じ回数にすること。）

2. 前項の回数を超える修正は、1回 ¥〔30,000〕（税込・総額）を申し受ける。
3. 構成案の承認後に構成そのものを変更する場合は、別途協議のうえ見積りを行う。

### 第5条（委託料および支払）
1. 本業務の委託料は **¥〔504,000〕（税込・総額）** とする。
   乙は適格請求書発行事業者の登録をしていないため、消費税を区分して請求しない。
2. 乙は着手金その他の前払金を請求せず、委託料の全額を納品後に請求する。
   甲は委託料を、**納品日から30日以内**に乙の指定口座へ振り込む。振込手数料は甲の負担とする。
   〔甲の締め日の都合により別の期日とする場合はここに記載する〕
3. 甲の都合により本業務が中止された場合、乙は次の割合により対価を請求できる。

| 中止の時点 | 請求できる割合 |
|---|---|
| 絵コンテの承認まで | 50% |
| 映像の生成に着手したあと | 80% |
| 初稿の提出後 | 100% |

### 第6条（著作権）
1. 本納品物が著作権法上の「映画の著作物」に当たり、同法第29条第1項により
   本納品物の著作権が甲に帰属する場合、甲および乙はその帰属を確認する。
2. 前項が適用されない場合、本納品物に関する著作権（著作権法第27条および
   第28条に規定する権利を含む）は、**委託料の支払完了をもって乙から甲へ移転する。**
3. 前2項のいずれの場合も、甲は本納品物を、用途・媒体・期間の制限なく使用できる。
4. 乙は甲に対し、納品物に関する著作者人格権を行使しない。
5. **生成AIにより制作された映像は、人の創作的関与の度合いによっては
   著作権による保護を受けない場合がある。**乙は、甲が納品物を使用することを
   妨げない限りにおいて責任を負うが、第三者が類似の映像を公表した場合に
   これを差し止められることを保証しない。甲が本納品物を使用できることは、
   第3項および第6条の2（独占的利用と転用禁止）により保証する。
6. 生成AIの性質上、学習データに由来する**意図しない類似**が生じる可能性を
   完全には排除できない。乙は既知の著作物を模倣する指示を行わないが、
   甲が納品物の公開前に、用途に照らして問題がないかを確認するものとする。
7. 甲が提供した素材（ロゴ・写真・音源等）の権利は甲に留保される。

### 第6条の2（独占的利用と転用禁止）
1. 乙は、本納品物および本業務のために生成した映像素材を、甲の書面
   （電子メールを含む）による承諾なく、第三者に提供し、または他の案件に使用しない。
2. 前項にかかわらず、乙は、本業務で用いた構成の型、演出の手法および
   プロンプトの設計方法そのものを、他の案件に用いることができる。
3. 本条第1項は、納品日から〔2〕年間存続する。

### 第6条の3（BGM・効果音）
1. BGMおよび効果音は、乙が商用利用の許諾を得た素材を使用する。許諾の範囲は、
   甲の〔自社サイト・YouTube・SNS・展示会・店頭サイネージ〕での利用に必要な範囲とする。
   この範囲での利用に追加の費用はかからない。
2. 前項の範囲を超える利用（テレビ・ラジオ放送、劇場上映、有償配信、他社への再提供等）を
   行う場合は、事前に協議する。追加の権利処理に要する費用は甲の負担とする。
3. 甲が楽曲を指定し、または提供する場合、その権利処理は甲が行う。
4. 配信先または第三者から権利の申し立てを受けた場合、乙は、使用した素材の許諾を
   示す資料を甲に提供する。

### 第7条（制作実績としての掲載）
1. 乙は、本業務の納品物および甲の名称を、乙のウェブサイト・SNS等に制作実績として
   掲載する場合、**掲載ごとに事前に甲の書面（電子メールを含む）による承諾を得る。**
   甲の承諾がない限り、掲載しない。
2. 甲が掲載を承諾しないことを理由として、委託料その他の条件は変わらない。

### 第8条（秘密保持）
両当事者は、本業務を通じて知り得た相手方の営業上・技術上の情報を、
相手方の書面による事前の承諾なく第三者に開示しない。本条は契約終了後も3年間存続する。

### 第9条（再委託）
乙は、本業務の一部を第三者に再委託できる。この場合、乙は再委託先の行為について
甲に対し責任を負う。

### 第10条（免責）
1. 乙は、納品物が甲の営業上の成果（再生数・問い合わせ数等）をもたらすことを保証しない。
2. 乙の責めに帰すべき事由により甲に損害が生じた場合、乙の賠償責任は
   **本契約の委託料の額を上限**とする。

### 第11条（契約の解除）
相手方に次の事由が生じたときは、催告なく本契約を解除できる。
支払いの停止、破産・民事再生等の申立て、本契約に違反し催告後14日以内に是正されないとき。

### 第12条（協議）
本契約に定めのない事項、または解釈に疑義が生じた事項は、両当事者が誠実に協議して解決する。

### 第13条（楽曲を扱う場合の特約）

**この条は条件付き。**MV・リリックビデオ・社歌など、甲が楽曲を用意する案件だけに付ける。
末尾に置いてあるので、付けても付けなくても前の条番号は動かない。

PDFを出すときは、手で消すのではなく **`make_doc.py` に `--music` を付ける／付けない**で
切り替える（2026-10-03）。条文の実体は `_書式/_楽曲特約.html` にあり、
契約書の本体をコピーした「MV用の別書式」は**作らない**——写しが増えると食い違う
（第6条の「意図しない類似」がHTMLに無かった事故がそれ）。

⚠️ 下の4項の「第5条3項」は**このMarkdownの番号**。HTML側は第5条が4項に
分かれているので `_楽曲特約.html` では「第5条4項」になっている。
どちらも自分の文書の中では正しいので、揃えようとして壊さないこと。

1. 甲は、本映像に使用する楽曲（以下「本楽曲」）について、著作権・著作隣接権
   その他必要な権利を有し、または権利者から本映像での使用および公開について
   許諾を得ていることを保証する。**乙は本楽曲の権利処理を行わない。**
2. 乙は、本楽曲を本映像の制作および第7条に定める実績としての掲載にのみ使用し、
   これ以外に利用しない。
3. 歌詞を映像に表示する場合、表記・改行・誤字の最終確認は甲が行う。甲の承認後に
   判明した表記の誤りの修正は、第4条1項の無償の修正回数に含めない。
4. 甲の都合により本楽曲が差し替わった場合、映像の構成が変わるため、両者協議のうえ
   別途見積もる。絵コンテの承認後に差し替わった場合は、第5条3項に準じて精算する。
5. 実在の出演者・アーティストの容姿を本映像に登場させる場合、本人の同意および
   参考素材の提供は甲が行う。AI による生成のため、容姿が実物と完全に一致することは
   保証しない。
6. 配信プラットフォームまたはレーベルの規約により、AI を用いて制作した旨の表示が
   求められる場合、その対応は甲が行う。乙は、AI を用いて制作することを
   第2条2項により事前に開示している。
7. 甲は、本映像のクレジットまたは配信時の概要欄に乙の名義（so-creative）を表示する。
   表示：〔　□ する　／　□ しない　〕
