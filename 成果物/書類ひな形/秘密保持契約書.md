# 秘密保持契約書（ひな形）

<img src="../ロゴ/logo-lockup.png" alt="so-creative" width="220">

**商談の段階（委託契約を結ぶ前）に使う。**PDFは次で出す。

```
cd ~/so-portfolio/discord-groupchat
./venv/bin/python tools/make_doc.py 秘密保持契約書 \
  --to "株式会社〇〇" --addr "〇〇県〇〇市..." --rep "代表取締役 〇〇"
```

条文は `_書式/秘密保持契約書.html` にある。**Markdownだけ直してもPDFには載らない**ので、
文言を変えるときは必ず両方を直すこと。

---

## いつ使うか

**出す場面（こちらから提案する）**

| 場面 | 出すか |
|---|---|
| 大手・上場企業との商談で、先方からNDAが出てこない | **出す** |
| こちらの構成案・絵コンテを、契約前に渡す必要がある | **出す** |
| 相手が「社内で共有して検討したい」と言った | **出す** |
| 先方からNDAが出てきた | **出さない**（先方のものに [[NDAチェックリスト]] で目を通す） |
| 初回の軽い問い合わせ・1回目の顔合わせ | **出さない** |

**⚠️ 初回商談の前に受注側から署名を求めると、たいてい嫌がられる。**
軽い段階では、見積書に入れてある「本書のお取り扱い」の注記で足りる。
**これを出すのは「資料を渡す直前」**と考えるとよい。

## 相手が修正を求めてきたら

飲んでよい／粘るべき、の線引き。

| 項目 | 本ひな形 | 相手の案を飲んでよいか |
|---|---|---|
| 期間 | 終了後3年 | 3〜5年なら飲む。**無期限は交渉する** |
| 賠償の上限 | 委託料（未締結なら10万円） | **上限を外す案は飲まない。**50万円の案件で青天井は割に合わない |
| 管轄 | 名古屋地裁 | 遠方を指定されたら、争うときの移動費を考えて粘る |
| 片務／双務 | **双務** | 一方的にこちらだけ負う形は、理由を聞く |
| **第3条（生成AIへの入力）** | **入れる** | **ここは外さない。**外すと運用が変わる |

**第3条がこのひな形の肝。**業務委託契約書 第8条2〜5項と同じ内容で、
「資料をAIに入れることがある／指定されたものは入れない／ロゴ・写真・音源は入れない／
学習に使わない設定があれば有効にする」を**先に書面で合意しておく**ためにある。
これが無いと、商談段階で預かった資料をAIに入れる行為が
「第三者への開示」に当たりうる。

## 条文の構成

| 条 | 中身 |
|---|---|
| 第1条 | 秘密情報の定義と、除外事由5つ（公知・事後公知・既知・第三者から適法・独自開発） |
| 第2条 | 秘密保持と目的外使用の禁止。法令・裁判所の命令は例外 |
| **第3条** | **生成AIへの入力**（上記のとおり） |
| **第4条** | **提案資料の取り扱い。**見積書・構成案・絵コンテの転載禁止と、著作権が乙に残ること |
| 第5条 | 複製の制限、終了時の返還・破棄（電磁的記録は通常の削除で足りる） |
| 第6条 | 有効期間1年、義務は終了後3年存続 |
| 第7条 | 損害賠償。**上限あり**（委託料／未締結なら10万円）。間接損害は含まない |
| 第8条 | **本契約は委託契約の締結義務を生じさせない。**締結後は委託契約の定めによる |
| 第9条 | 協議と管轄（名古屋地裁） |

## 関連

- **業務委託契約書 第8条**（秘密保持）… 契約【後】の定め。双務・3年。本契約はその【前】を埋める
- **NDAチェックリスト** … 先方のNDAを受け取ったときに見る側
- **見積書「本書のお取り扱い」** … NDAを出すほどでない場面の、軽い版
