# 料金改定（2026-10-13・実施済み）

**短尺と長尺を下げた。60〜90秒は据え置き。どの組み合わせも旧価格を超えない。**

## 変えたこと

| | 旧 | 新 |
|---|---|---|
| 企画・構成費（1案件に1回） | ¥80,000 | **¥100,000** |
| 2本目以降（1本につき） | ¥100,000 | **¥80,000** |
| 時間単価の下限（`RATE`） | ¥23,000/h | **¥20,000/h** |

**秒単価は「合計の尺が長いほど下がる」逓減にした**（旧は段ごとに1つの単価）。

| 段 | 最初の30秒 | 31〜90秒 | 91秒以降 |
|---|---|---|---|
| 梅 | ¥5,500 | ¥4,500 | ¥3,200 |
| 竹 | ¥7,400 | ¥5,700 | ¥4,300 |
| 松 | ¥10,500 | ¥8,000 | ¥6,400 |

**⚠️ 逓減は「合計秒数」（1本の尺 × 本数）にかかる。1本ごとに区切ってはいけない。**
**⚠️ 段の倍率を3段すべてにかけてはいけない。**かけると松の中尺が値上がりする
（30秒 +2% / 60秒 +3% / 90秒 +4%）。旧価格は linear なので、基本料金を下げたぶんを
秒単価で埋め戻すと松ほど埋め戻しが大きくなる。段ごとに個別の数字を持たせてある
（松の実効倍率は 1.91 / 1.78 / 2.00）。

## 機械で検査したこと

**9,717通り（尺8種 × 段3 × 本数1〜6 × ナレーション3通り）**で、

- 旧価格より上がる組み合わせ … **0件**
- 時間単価 ¥20,000/h を割る組み合わせ … **0件**（最低 ¥22,307/h）
- **クレジット原価（¥316/秒）を引いた後**も ¥20,000/h を割らない … 最低 **¥20,279/h**

**原価を引いた後の下限を最初は見落としていた。**テストの `RATE` は 価格÷工数 で、
クレジット原価は工数モデルに入っていない。既存の「クレジット原価が秒単価の10%未満」
という検査が鳴って気づいた。梅の91秒以降を ¥2,900 → **¥3,200** にして解消した
（¥2,900 のままだと 梅・合計600秒以上・2本以上の1,192通りが ¥18,450〜19,996/h になる）。

**サイト／見積書PDF／Discordボットの3つを432通りで照合し、ズレ0件。**

## まとめ買いの見せ方が変わった

旧：まとめると常に ¥80,000 安い（`base − perExtra` の固定）
新：**合計の尺が長いほど差が大きくなる**（逓減が効くため）

| 同じ尺を2本 | 旧 | 新 |
|---|---|---|
| 15秒×2 | ¥80,000 | ¥20,000 |
| 30秒×2 | ¥80,000 | ¥50,000 |
| 60秒×2 | ¥80,000 | **¥89,000** |

本数加算を ¥100,000 のままにすると「2本目は＋¥160,000」が **＋¥182,500 に値上がり**して
見えたので、¥80,000 に下げた（＋¥162,500 でほぼ据え置き）。

## 見積書の内訳（合意した形）

```
企画・構成費                            ¥100,000
尺（最初の30秒）  30秒 × ¥7,400        ¥222,000
尺（31〜90秒）    30秒 × ¥5,700        ¥171,000
合計（竹・60秒・1本・AI）              ¥493,000
```

「60秒 × ¥5,400」のように1つの単価で書くと嘘になるので、**該当する段だけ行に分ける**。
1本のときは「追加の本数」の行を出さない。

## 残っていた取り残し（この改定で見つけて直した）

1. **`index.html` の FAQ と料金のリード文**に旧の式（企画費¥80,000＋制作費¥100,000×本数、
   秒単価 梅4,000/竹5,400/松8,000）が残っていた。**1,603件のテストが全部通ったまま**
   公開ページに古い式が残る状態だった → 守り手を追加（下）
2. **`pricing.html` の秒単価の行**と計算機の静的な初期表示が旧単価
3. **ボットの `MY_PRICING_NOTE`**（AI に渡す説明文）が**2世代前**の価格
   （秒単価 梅3,500／竹4,900／松6,650、基本料9万、2本目＋6.5万）。
   2026-10-04 に計算（`_quote_text`）だけ直して、説明文を直し忘れていた
4. **`exhibition-video.html`** の「会社紹介60秒・竹にブース用15秒＋¥160,000」は
   竹の案件に**梅の秒単価**で計算されていて ¥21,000 少なかった（竹の額へ訂正）
5. `record.html` の「梅は5〜6%しか下げられない」は、同じ節の表（38%引きまで可）と
   矛盾しており、根拠が見つからなかったので数字を落とした

## この改定で間違えたこと（繰り返さないために）

1. 尺を5種類で試算した（実際は 15/30/45/60/90/120/180/**300** の8種類）
2. 逓減を本ごとに計算した（**実際の秒単価は合計秒数にかかる**）
3. 段の倍率をかけると松が値上がりすることに、3回目の試算まで気づかなかった
4. **時間単価の下限をクレジット原価の前で見ていた**（¥20,000/h は原価を引く前の数字）

**料金は1回で正しく出そうとせず、全組み合わせを機械的に回して確かめること。**
**「公開中だから正しい」とは限らない。数字は式で検算すること。**
