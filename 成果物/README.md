# 成果物/

つくったものの置き場。Discordのボットが作るファイルと、
Claude Code のセッションで作るものの両方が入る。

## 何がどこにあるか

| フォルダ | 中身 |
|---|---|
| `書類ひな形/` | **見積書・請求書・業務委託契約書。**お客様に出すPDFはここから作る（`README.md` に出し方） |
| `_テンプレート/` | 営業文面・送り先リスト |
| `送り先リスト/` | **実際の送り先。**名古屋・採用動画30社＋**◎11社ぶんの差し込み文**（2026-09-24。県の公開情報から絞ったもの）。**開業届を出すまで送らない** |
| `開業準備/` | **開業チェックリスト。**期限・開業費・自己破産・傷病手当金との関係（出典リンクつき／2026-09-24時点） |
| `ロゴ/` | so-creative のロゴ（SVG・PNG・壁紙）と、決めるまでの検討 |
| `サイト/` | サイトがどこにあるかと、直し方（**サイト本体は `main` にある**） |
| `〇〇工業_会社紹介動画/` | 営業ロープレで作った案件一式（**架空のクライアント。実案件ではない**） |
| `映像の型/` | **毎朝のYouTubeリサーチ177件を畳んだもの。**会社紹介動画とMVの型（カット尺の実測・AIで作れる/作れない・相場） |
| `事例素材一覧/` | 前職の事例動画106本の映像分析。自分用の参考資料 |
| `NotebookLM用/` | 前職の資料を読み込ませるために整形したもの。**自社の数字ではない** |
| `サンプル映像/` `ビジュアル制作/` `律速段階PV/` | 制作の途中でできたもの |


- 案件ごとにフォルダを分ける（例: `成果物/スキンケアPV/構成案.xlsx`）
- **`main` にも自動で載る**ので、スマホでGitHubを開いたまま
  （既定の表示のまま）見られる。Macが落ちても消えない。
- 同じ表題で作り直すと上書きされるが、前の版はGitの履歴に残る。

## GitHubでの見つけ方

上部の「**Code**」タブ → `成果物` フォルダ。

※上部の「**Projects**」タブは**別物**（カンバンボードの機能）。
ファイルは入らないので、そこを見ても何も無い。
以前この取り違えで「入ってない」となったため、フォルダ名を
`projects` から `成果物` に変えてある。

※`.xlsx` はGitHub上でプレビューできない。ファイルを開いて
ダウンロードボタンから落として使う。Discordに届く添付を
そのまま開くのが早い。
