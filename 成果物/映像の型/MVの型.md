# MVの型

毎朝の自動リサーチ（`discord-groupchat/fixtures/youtube_insights.md` の時系列）のうち、
**「ミュージックビデオ」系の記録を横断して畳んだもの**。
対象期間 2026-07-14 〜 2026-09-23、記録 約85件。

**数え方の断り**：「実測」は各日の分析が **「数えた」と明記した値だけ**。
「推定」の値は分布の集計から外した。平均秒数は「1本ごとの平均」の集まり＝**平均の平均**である。
絵コンテを切るときの相場観として使うこと。

## 2. テロップは二極化している（中間がない）

| 型 | 実例 |
|---|---|
| **一切出さない** | 09-22 18:34：LE SSERAFIM・ふみの・Aぇ!group・Odyle（5本中4本）が歌唱中の歌詞テロップ皆無。09-22 08:05：MV5本ともロゴ文字が冒頭0:01〜0:02に1回（10文字前後）出るだけで、以降エンドロールまで無し。VIBEX は80〜90カット・1〜2秒の超高速編集でもテロップ無しで押し切っている |
| **発話タイミングに完全同期** | VELVET I・BE:FIRST・VIBEX（歌詞をポップアップ）、田中幹也 8〜12字／枚、音乃瀬奏 10字前後、藤井風 20〜35字、YOASOBI系 4〜15字、Juice=Juice系 2〜12字。位置は **画面下部中央に固定** |

M!LK では **メンバー名テロップ（2〜6字）がカット切替と完全同期** していた。

→ **どちらかに振り切る。** 「なんとなく歌詞を出す」は、実測上どの本にも存在しない。
テロップを常時出し続ける会社紹介動画とは真逆の設計であることに注意。

## 3. 冒頭の型

- **人物ではなく物体のクローズアップから入る**：Sugar Soul は部屋、きゃわぽっぴんどぅーは
  ガムボールマシン（09-23 11:53、実測2本とも）
- **黒背景＋白文字ロゴを0.5〜2秒**（NF RECORDS／KVI BABA型）
- **暗闇から中央上部に光が広がる3秒の無音オープニング**（玉置浩二型）。ロゴ無しの抽象導入
- 08月の記録では「**変則ファーストカット**（グラスの底、瞳のドアップ）で一瞬『何の映像か？』と
  思わせる」が繰り返し挙がっている

共通しているのは **引きの説明カットから始めない** こと。

09-23 18:39：5本中4本が **引きの集合カット（7〜16人）を1〜2秒に抑え、寄りの顔カットへ素早く切り替える**。

## 5. 演出の引き出し（8月の記録から、頻出順）

同じ技法が何度も繰り返し挙がっていたものを、出現頻度の高い順に並べた。

1. **ビートシンク** — 楽曲のキック・スネアに1フレーム単位でカットを同期。サビで加速。
   全期間で最頻出。「実装優先度：ビートシンク ＞ マッチカット ＞ ローアングル」（08-23）
2. **マッチカット** — カメラ位置を完全固定し、ポーズを揃えたまま衣装・背景だけ瞬時に切替。
   エフェクトに頼らず、追加ロケ無しでワープ感を出せる
3. **寄り引きの極端な緩急** — 顔の超クローズアップ（魚眼風の超広角）↔ ドローンの俯瞰。
   クローズアップ：ロングを **1:3** の比率で交互に、という具体的な配分も記録されている（08-11）
4. **異物越しPOV** — グラスの底、コピー機の内側、窓枠、冷蔵庫の奥、車のバックミラー。
   普段見られない視点にカメラを置くだけで、低予算でもシネマティックになる
5. **環境音の楽器化（音ハメ）** — ストローを吸う音、足音、シャッター音、氷の音を
   ビートの一部として精密にミックスする
6. **マルチロケーション＋衣装替え** — 最低3〜5ロケ。数秒おきに視覚的な変化点を作る
7. **ロケごとのキーカラー固定** — 青＝海／緑＝庭／黄赤＝レトロ。色分けで世界観を分離する
8. **昼夜のライティング転換** — 同一ロケで自然光と夜の電飾を使い分け、
   ロケを増やさずに視覚バリエーションを2倍にする
9. **SNS UI の3D空間配置** — 通知・コメントを平面テロップでなく、映像内の奥行きに合わせて配置
10. **小道具起点のトランジション** — シャボン玉・マッチの炎・モップ・アイス・水滴・花びらを
    視線誘導のトリガーにして場面を繋ぐ
11. **静→動の落差** — 無音／静寂から一気に音を解放する。無音を1箇所だけ挟むと緊張感が際立つ
12. **色調を1本に絞る** — 単色グレーディングだけで、素材の質を超えて世界観の統一感が出る

## 6. 市場の構造（受注判断に効く部分）

- 再生数上位は **HYBE系K-POP（&TEAM／LE SSERAFIM／ENHYPEN／IU／D.O.）が独占**。
  リリース直後の初速で決まる。制作費と再生数は必ずしも比例しない
- **本編以外の二次コンテンツが伸びる**のが一貫した傾向：
  メイキング／舞台裏／Test版／Audio版／Performance版／リアクション。
  サカナクションの「MVで大失敗！？」は本編級の再生を取った
- **THE FIRST TAKE型（一発撮り）は低予算でも高視聴が狙える型**
- タイトルは「アーティスト名＋曲名＋Official MV」の定型が鉄板。装飾語を排除した方が公式感が出る
- **AI生成MVツールが実用段階に来ている**（09-21、Solmi AI）：
  楽曲解析 → 絵コンテ自動生成 → シーン単位の部分修正（「昼→夜」等のプロンプト微調整のみ）
  → リファレンス画像で同一人物の一貫性維持、という一気通貫のワークフロー

→ **受注の示唆**：本編1本で終わらせず、同じ素材から「本編＋裏側ショート＋Audio版」を
出す設計を最初から提案する。これは企業の事例動画にもそのまま輸入できる（複数日で指摘あり）。

## 7. AIで作れるもの・作れないもの

### 作れる

| 対象 | 手順 |
|---|---|
| **背景単体**（車・自然風景・サイバーパンク都市・森・夜景・都市俯瞰） | プロンプトのみで生成 → 編集で切るだけ。またはカメラのみ微動する3〜5秒に |
| **顔が特定できない暗所のカット**（抱擁・水滴・手元クローズアップ） | 寄り構図＋逆光を指定。顔の一貫性を問われない |
| **同一人物 × 環境違い** | リファレンス画像で顔を固定し、各カット**5秒以下**で個別生成して繋ぐ |
| **単色背景＋ダンサー群像の後ろ姿** | 背面指定なら顔一貫性の破綻を問われず、コストが落ちる（米津玄師型） |
| **顔が判別できない引きの群衆・観客** | 2〜3秒で複数パターン生成し、実写メインカットの合間に差し込む |
| **非人物の象徴カット**（オーケストラ全景・電飾・小物） | 静止画生成 → 2〜3秒の微小カメラ移動 → ビートに合わせて差し込む |
| **抽象的な発光パーティクル・光の帯** | 静止画生成 → 浮遊・発光のみ指定。**ロゴ文字は入れない** |
| **マクロのオブジェ**（黄金の液体・ガラス片） | `golden liquid crystal shatter, dark background, macro` → `slow shimmer, subtle refraction, static camera` で3秒ループ |
| **スポーツの静止フォーム** | 構えの静止画を作り、動画AIに「カメラのみ動かす、被写体は静止」と指示 |
| **表情バリエーション** | 同一キャラのプロンプトで 怒り／悲しみ／驚き／笑顔 を複数生成し、カットごとに差し替え |
| **決めポーズのダンスカット** | 平均2.6秒という短尺の範囲なら、長尺の一貫性を要求されないので破綻しにくい |
| **黒背景＋白文字ロゴの冒頭カット** | 無地背景を静止画生成し、**文字はAIに書かせず後合成** |

### 作れない

| 対象 | 理由 |
|---|---|
| **歌唱と同期した長尺のリップシンク・身体接触動作** | 関節位置がフレームを追うごとに崩れ、音ともズレる。実写かモーキャプが必須 |
| **実在アーティストの顔を保ったままの長尺ダンス** | 顔の同一性維持と関節の物理挙動を同時に保証できず、カットが長いほど破綻する |
| **1カットに9〜30人以上の密集構図** | 人数が増えるほど個体の位置・重なりの破綻率が上がる（きゃわぽっぴんどぅー9人、ヒロアカ30人以上） |
| **複数キャラが同一楽曲のリズムで同時に別々の演奏動作をする一貫性** | 被写体ごとに独立して動きを作るため、全員をテンポに同期させたまま保持できない |
| **衣装・ヘアメイクを2.6秒間隔で変えながら顔を全編一貫させる** | 参照画像を都度差し替える必要があり、生成のたびに顔がわずかにズレる |
| **同一セットの保持**（幾何学ステージ美術・スパンコール衣装） | カットごと独立生成なので照明・装飾の位置が毎回変わり、同一舞台の説得力が出ない |
| **ビート位置にミリ秒単位でカット点を合わせる編集判断** | 絵は生成できても、波形合わせは人力（サカナクション171カット・1.3秒） |
| **カメラが寄る速度・タイミングの制御** | 1カット内のパン・ズーム速度を狙って指定できない（なにわ男子 0:00-0:03） |
| **テロップがカット切替と完全同期する編集** | カット点の選択自体が演出判断なので自動化できない（M!LK のメンバー名テロップ） |
| **1カット10秒以上の身体接触ノーカット** | 抱き合う・絡むといった接触点の位置が動きと共にすぐ崩れる |

料金は `discord-groupchat/tools/make_doc.py` の式（基本料 90,000円 ＋ 秒単価 × 秒数、

| 実例 | 尺 | 階層 | 金額 | 工数の見込み |
|---|---|---|---|---|
| サカナクション型の高速カット 6〜8カット | 15秒 | 竹 | 約163,500円 | 約2.8h |
| 米津型（単色背景＋群像の後ろ姿）6カット | 15秒 | 竹 | 約163,500円 | 約2.8h |
| なにわ男子型の高速カット 8カット（集合は1.5秒以内） | 15秒 | 竹 | 約163,500円 | 約2.8h |
| ストレッチチャレンジ型 8カット（テロップ同期＋BGM主体） | 20秒 | 竹 | **188,000円** | 約3〜4h |
| 10〜15カット・人物一貫性あり | 30秒 | 竹 | 約237,000円 | 約5.7h |
| ONE OK ROCK型 10カット（LoRA/IP-Adapter調整が要る） | 30秒 | 竹 | 約237,000円 | 約5.7h |
| Bon Jovi型 18カット（実在人物差し替え＋ナレ同期） | 39秒 | 竹 | 約281,100円 | 約7.4h |
| 田中幹也型 14カット（歌詞同期テロップの位置合わせ多め） | 44秒 | 竹 | 約305,600円 | 約8.3h |

> 20秒・竹の行について：元のリサーチ記録は「約17.8万円」と書いていたが、
> 9万＋20秒×4,900＝**188,000円** が正しい（2026-09-22 に判明した計算ミス。
> `test_routing.py` に再発防止のテストが入っている）。ここは訂正済みの値を載せてある。

**MVは会社紹介動画より松に上がりやすい。** 理由は一つで、**顔・ダンス・リップシンクの生成失敗率**。
逆に「高速カット割りは AI生成コストと破綻リスクが比例する」ので、
15秒・6〜8カットのような短尺は松まで上げず竹で吸収できる、という判断がログに残っている。

## 9. 両ジャンルに共通する4つ（会社紹介動画側の分析と突き合わせた結果）

MVと会社紹介動画は見た目が全く違うのに、AI制作上の制約は同じ4つに集約される。

1. **AIの破綻はカット尺で隠す。** 1.5〜2秒に抑えれば顔や手足の崩れはほぼ見えない。
   逆に長く見せたいカットほど実写が要る
2. **顔を避ける構図が最大のコスト削減。** 後ろ姿・手元・シルエット・暗所・引きの群衆
3. **文字はAIに書かせない。** ロゴ・社名・看板・図面・QR・UI。すべて後合成。
   これは全期間で一度も例外が出ていない
4. **編集判断は代替できない。** 音に合わせる／尺を詰める／どの情報を何秒出すか。
   ここが人の工数として丸ごと残る

## 10. まだ試していない検証（リサーチが毎日積んだ宿題）

「次に試すこと」として記録されたまま、実行された形跡がないもの。上から筋が良い順。

- [ ] 生成した5秒クリップ1本を、クロップ位置とズーム率違いで**3分割して3カットとして繋ぐ**。
      生成コストを増やさずカット数を稼げるか（09-23 13:34）
- [ ] 同一人物の参照画像を使い、環境だけ変えた5秒カットを2つ（砂浜／夜景）生成し、
      **顔の一貫性が保てるか**（09-22 18:34）
- [ ] 集合カット（8人以上）を**静止画生成のみ**で用意し、動画化せず1.2秒だけ表示して次へ切る。
      高速カット編集の中で違和感が出ないか（09-23 18:39）
- [ ] メインボーカル1名を手前に動画AI化、背景の10名前後は静止画のまま別レイヤーで配置し、
      **大人数の破綻を避けつつ「動きがある」印象**を出せるか（09-23 11:53）
- [ ] 歌詞1フレーズ（4〜12字）を**静止画のテキストプレート**として先に作り、
      動画生成した背景に後合成する。AIに文字を書かせずに済ませられるか（09-23 10:04）
- [ ] 顔が映らない暗所の抱擁シルエットを3秒×3カット生成し、
      歌詞テロップのポップアップと発話タイミングを合わせて編集する（09-22 20:14）
- [ ] BGMのBPMからビート間隔を算出し、1.5秒前後の短尺カットを8本生成して
      **ビート単位で自動配置**する編集（09-22 21:57）
- [ ] 液体／ガラス片オブジェを「カメラ固定・被写体のみ微細に発光・振動する3秒ループ」で作り、
      イントロの待機カットに使えるか（09-23 16:54）
- [ ] 手の動きを含む被写体（料理・チェロ演奏）を超クローズアップ×2〜5秒で生成し、
      **指・弓の形が崩れないか**（09-21）

## 11. 絵コンテ前のチェックリスト

- [ ] カットは1.2〜3.6秒の帯に入っているか。カット数は60〜90本を目安にしたか
- [ ] テロップを「一切出さない」か「発話に完全同期」のどちらかに振り切ったか
- [ ] 冒頭を引きの説明カットで始めていないか（物体のクローズアップ／黒背景ロゴ／無音の光）
- [ ] 集合カットを1〜2秒に抑え、寄りの顔カットへ逃がす設計にしたか
- [ ] ビートシンク → マッチカット → 寄り引きの緩急、の順で優先して仕込んだか
- [ ] AIに顔の長尺・大人数・文字を任せようとしていないか
- [ ] 本編だけでなく、裏側ショート／Audio版の派生を提案に入れたか
- [ ] 階層は尺ではなく「顔とダンスの生成失敗率」で決めたか
