# 会社紹介動画の型

毎朝の自動リサーチ（`discord-groupchat/fixtures/youtube_insights.md` の時系列）のうち、
**「会社紹介動画 制作事例」「企業VP」「コーポレートムービー」系の記録を横断して畳んだもの**。
対象期間 2026-08-28 〜 2026-09-23、記録 約90件。

**数え方の断り**：以下の「実測」は、各日の分析が **「数えた」と明記した値だけ** を拾っている。
「推定」と書かれた値は分布の集計から外した（本数が少ないので、推定を混ぜると帯がぼやけるため）。
平均秒数はさらに「1本ごとの平均」の集まりなので、**平均の平均**である。
厳密な母集団統計ではなく、絵コンテを切るときの相場観として使うこと。

## 1. まず市場の事実（ここを外すと全部ズレる）

**会社紹介動画は YouTube で再生されない。** これは繰り返し同じ結論が出ている。

- 正統派の会社紹介動画の再生数は **数十〜1,500回** が大半（09-18、09-11 ほか複数日）
- 「企業VP」で検索して上位に出るのは **ナレーター／声優のボイスサンプル**。
  08-28 は7本中6本、09-01 は14本中10本、09-06・09-07・09-08 も同じ結論。
  最高再生でも 167〜229回。**VP本編は限定公開の納品物なので、そもそも表に出ない**
- 09-08 の要約が端的：「客じゃなくて、発注者に向けた営業素材ばかり出てくる」

→ **KPIを再生数に置かない。** この領域の動画は「指名検索で見つかること」
「商談で見せられること」「採用ページ・営業資料に埋め込めること」が価値。

**では何が再生されているか**（上位に食い込んでいたもの）

| 伸びていたもの | 例 |
|---|---|
| 具体ベネフィットを数字で言い切るサービス訴求 | 「30秒自動見積もり」「爆速・格安・丸投げOK」（複数日で1位） |
| 「制作事例」を連番シリーズ化したポートフォリオ | #21〜25 のようなナンバリング（09-10） |
| 採用難の現場業種 × 社長の顔出し密着 | 運送・建設・足場・電気工事（09-01）。「29歳足場屋社長」型 |
| 企画性のある副題 | 「怪獣＆ヒーロー編」「休みでリフレッシュ篇」「猫が働く鉄鋼所」 |

逆に **伸びなかった** のは「【社名】会社紹介動画」という定型タイトルだけのもの。
これは全期間を通じて一貫している。

### 尺を決めているのはナレーション

これが一番使える発見。09-23 の記録に明確に出ている。

| | 実測 |
|---|---|
| **ナレーション無し**（人生物語ワークス25カット・トムコ49・堀商40） | 平均 **1.5〜2.3秒** |
| **ナレーション有り**（明和工業19カット/141秒・興和オプトロニクス30/282秒） | 平均 **7.4〜9.4秒** |

**ナレ無しの方がカットが3倍前後速い。**
さらに 09-23 16:50 では「ナレーション一文の区切り＝カット切り替え＝テロップ表示」が
**1:1で一致** する構成が5本中4本で共通していた（老人ホーム・金物屋・治療コンセプト・パパっと育児）。
平均秒数が2.6〜7.4秒とバラついて見えるのは、**文の長さに尺を合わせている**から。

→ **先にナレーション原稿と音声を確定させ、その発話区切りでカットを割る。**
「何秒のカットを何本」から入ると、必ずどこかで合わなくなる。

## 3. 構成の型

### 尺と全体構成

- **長尺（3〜13分、最頻は7分前後）**：理念 → 事業紹介 → 社員インタビュー → 働く環境／未来、の4幕。
  採用目的（新卒／中途）を明記するものが多い
- **短尺（60〜90秒）**：TOPPAN型の「90秒でわかる」。冒頭3〜4秒で業種と便益を提示し、
  テロップ主導で圧縮する
- **2尺セット納品**が繰り返し推奨されている（09-17、09-18、09-08）：
  **「90秒ダイジェスト」＋「7分フル」**、または フル尺＋30秒切り出し。
  営業でも採用ページでも使い回せるので、提案材料として強い
- **縦型9:16の抜き出し**を同時納品（09-02）。SNS転用まで前提にすると単価あたりの回収率が上がる

### 冒頭の型

| 入り方 | 出典 |
|---|---|
| **単色背景＋社名ロゴのみの0〜3秒**（無音かBGMのみ）→ 実写／CGへ | 09-22：酒井工業・伊藤忠・J.A.X.I.A・ミクニ機工の4本で共通 |
| 線画／CGアニメの導入2〜5秒 → 実写の証言部へ、の二層構成 | 09-22：八木製作所・ヒューマンセントリックス |
| 冒頭3〜4秒で業種と便益を言い切る | 09-11、09-03（「冒頭2秒で対象業種を名指し」） |
| 日常の違和感・意外性から入る | 09-16：ビー玉が転がる（家屋調査士）／海のない板橋でウニ |
| ミクロ⇄マクロの対比（半導体の寄り → 都市のドローン俯瞰） | 09-11：TOPPAN |

共通するのは **「専門的で難解な内容を、視聴者の日常に一度落としてから入る」**（09-16）。

### 離脱を防ぐ仕掛け

- **チャプターの常時表示**：画面隅に「その①〜」「ステップ○/○」「◯◯モード」を出し続ける
  （ミクニ機工、ギガフォトンの進捗フロー図、09-13・09-18）
- **画面分割＋モーショングラフィックス**：素材が少ない企業でも情報量を作れる（LOCUS型、09-18）
- **発言に完全連動するBロール**：インタビュー中の単語と寸分違わぬ実務映像を重ねる（09-13・09-14）

## 4. テロップの型

**テロップ帯を画面の同じ位置に固定し、最初から最後まで出し続ける。**
09-23 のシンワ・NRIセキュア・済生会・谷川屋の4本（5本中4本）で共通。

字数は「要約字幕」型が主流（09-23 15:10）：

- ナレーション**全文を出さない**。要点だけを **10〜20字** で画面下部に
- 別の日の実測では **1枚あたり最大30字程度**（09-23 07:10）
- テロップの出現・消去が **ナレーションの発話区切りと完全一致**

→ 音を切っても内容が伝わる設計（ミュート視聴・年配層への配慮、09-14）。

## 5. 音の型

- **環境音を切り、ナレーション／インタビュー音声＋BGMのみ**に整理する。
  09-23 18:35 で5本中4本（Orike・ひかり整骨院・クロステリア・池袋学園）が該当
- BGMは序盤静か → 終盤に向けてビルドアップ（09-14）
- 生音を残すのは要所だけ（掛け声・機械音・接客の挨拶）。ここでメリハリが出る（09-04・09-14）
- **「間」で信頼感を作る**：言葉を詰め込まず、BGMに合わせて贅沢な間を取る（08-30）
- 定番のBGM編成は **アコギ＋ピアノ＋チェロ**（09-07）。
  用途別では 挑戦・誠実＝ピアノ＋ストリングス／安心＝アコギ／客観＝ピアノ単音（08-30）
- 中盤だけBGM音量を下げて生インタビューに主役を譲る、という**動的なミックス**が
  大和証券で使われていた（09-23 15:10）。これは後述のとおりAIでは作れない

## 6. AIで作れるもの・作れないもの

9月下旬のリサーチは、毎回この切り分けを記録している。事業に直結するのでそのまま残す。

### 作れる

| 対象 | 手順 |
|---|---|
| 工場・オフィス・測量現場などの**汎用背景** | プロンプトのみで生成。テロップは編集ソフト側で別レイヤー |
| **手元アップ**（書字・機械操作・PC作業・調理・演奏） | 2〜5秒の短尺で個別生成。正面顔を使わないので一貫性の崩れが露出しない |
| **単色背景＋ロゴのフェード冒頭カット** | 静止画生成 → ロゴ合成 → 動画AIに「ズーム/パン無し」を指定、BGMのみ |
| **機械・製品のクローズアップ群** | Kling/Seedance で5秒ずつ生成し、編集で2.2〜3.3秒に間引く |
| **製品の水平パン** | 実物商品写真を基準画像に、カメラを右→左へゆっくり動かす5秒動画（谷川屋型） |
| **1枚絵の疑似回転** | Image-to-3D で立体化 → 8方向レンダリング → 繋ぐ（ポプルス85秒相当） |
| **フラット2Dイラストの人物** | スタイル／シード固定で複数生成 → 「頷く」「腕を上げる」等の簡易動作を付けて3秒カット |
| **アニメ・イラスト調の人物** | 写実調より顔の微細なブレが目立たない（池袋学園型）。様式内なので許容される |
| **抽象モーション背景**（歯車・波形・パーティクル） | パーツを静止画生成 → 回転のみ指示 |
| **脇役として入れ替わる人物** | 顔の一貫性が不要な人物を個別生成 → ナレーション一文ごとに1カット割り当て |

### 作れない

| 対象 | 理由 |
|---|---|
| **企業ロゴ・社名・看板の正確な文字** | 生成AIの文字レンダリングが不安定。実写撮影か後合成が必須（ITOCHU、ニッコー、ガイア、栄商事、lumielune で繰り返し確認） |
| **実在メーカーの精密機械の実機** | 外観・パーツ配置が図面通りでないと成立しない（DORNIER社・BROETJE社） |
| **設計図・仕様図面** | 図面らしい絵は作れても、意味を持つ寸法・仕様データは入らない（クラフトアール） |
| **Webサイト・ソフトウェアの実画面** | 実在サービスのUIではなく空想のUIを作ってしまう。画面録画が必須 |
| **QRコード** | 見た目が似た模様は作れても、実際に読み取れる配列は再現できない（機能要件） |
| **社長・社員インタビューの証言部** | 精度以前に「本人が実際に話した」という真正性そのものが価値。代替する意味がない |
| **20秒を超える連続ワンカット** | 生成AIの上限が数秒〜十数秒。一貫性以前に尺の制約（アイジー社28.3秒） |
| **対談の即興的な相槌・間** | 台本のない反応のタイミングは事前生成できない |
| **音声ミックスの緩急** | 内容の重要度に応じた動的な音量調整は出力対象外（大和証券） |
| **ナレーション尺に合わせた編集判断** | 生成した動画を後から音声に合わせて伸縮できない。人力で尺を詰める工程が必須 |

**まとめると、AIで置き換わるのは「絵の素材」だけで、「どの絵を何秒出すか」は丸ごと残る。**
これは値付けの根拠になる（工数が消えない理由の説明として使える）。

## 7. 受けるときの相場（実例）

料金は `discord-groupchat/tools/make_doc.py` の式（基本料 90,000円 ＋ 秒単価 × 秒数、
秒単価は 梅3,500／竹4,900／松6,650）。以下は09-22〜09-23に実際の分析動画へ当てて出した見積り。

| 実例 | 尺 | 階層 | 金額 | 工数の見込み |
|---|---|---|---|---|
| イラストのみ11カット構成 | 30秒 | 梅 | 約195,000円 | 約4.7h |
| AI背景＋テロップ主体、人物は単カット | 60秒 | 梅 | 約300,000円 | 約9.3h |
| 短尺つなぎ18カット | 60秒 | 竹 | 約384,000円 | 約11.4h |
| 25カット・実在ロゴあり | 58秒 | 竹 | 約374,200円 | 約11.0h |
| 12カット・顔一貫性あり | 30秒 | 竹 | 約237,000円 | 約5.7h |
| 15カット・ポーズ差し替えあり | 60秒 | 松 | 約489,000円 | 約12.7h |
| 済生会型・人物5名の顔一貫性 | 112秒 | 松 | 約834,800円 | 約23.7h |

**階層の判断基準（ログから読める運用）**

- **梅**：実写なし／キャラ一貫性が不要／人物は単カットのみ（顔の破綻リスクが低い）
- **竹**：テロップと音声の同期作業が要る／複数人物は出るがリップシンクは不要
- **松**：複数人物の顔一貫性が要る／ポーズ差し替え／実写合成

参考：伊藤忠型（225秒・68カット）を梅で受けると 78.75万＋基本料9万＝**約88万円**だが、
AIで作れるのは機械の寄りだけで大半が実写編集になるため、実際は松向き・工数30h超という評価だった。
**尺だけで階層を決めない。**

## 8. 両ジャンルに共通する4つ（MV側の分析と突き合わせた結果）

会社紹介動画とMVは見た目が全く違うのに、AI制作上の制約は同じ4つに集約される。

1. **AIの破綻はカット尺で隠す。** 1.5〜2秒に抑えれば顔や手足の崩れはほぼ見えない。
   逆に長く見せたいカットほど実写が要る
2. **顔を避ける構図が最大のコスト削減。** 後ろ姿・手元・シルエット・暗所・引きの群衆。
   「顔を映さない会社紹介」は実際に検証項目として挙がっている
3. **文字はAIに書かせない。** ロゴ・社名・看板・図面・QR・UI。すべて後合成。
   これは全期間で一度も例外が出ていない
4. **編集判断は代替できない。** 音に合わせる／尺を詰める／どの情報を何秒出すか。
   ここが人の工数として丸ごと残る

## 9. 絵コンテ前のチェックリスト

- [ ] この動画のKPIを再生数に置いていないか（指名検索・商談・採用ページのどれか）
- [ ] ナレーション原稿を先に確定したか。カット割りをその発話区切りに合わせたか
- [ ] ナレ有りなら4〜9秒、ナレ無しなら1.5〜2.3秒。狙いの帯を決めたか
- [ ] 冒頭3〜4秒で「誰の・何の話か」を出したか（社名ロゴだけで終わっていないか）
- [ ] テロップ帯の位置を固定したか。1枚10〜20字に収まっているか
- [ ] 環境音を切ってナレ＋BGMに整理したか。生音を残す箇所を決めたか
- [ ] AIに文字（ロゴ・看板・図面・UI）を書かせようとしていないか
- [ ] 90秒ダイジェスト＋フル尺、縦型抜き出しの2尺セットを提案したか
- [ ] 階層（梅竹松）を尺ではなく「顔の一貫性が要るか」で決めたか
