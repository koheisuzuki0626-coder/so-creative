### テロップの作り（B案を採用）

平凡な白抜き文字をやめ、映像に溶かす方向にした。

- ネイビー `#0f2140` の帯を不透明度85%で下1/4に敷き、`scaleX` を0→1で0.32秒で開く
- 帯の左端に白の縦バー（幅6px）を `scaleY` 0→1で0.35秒で立てる
- 本文は IPAPGothic 700、`motion={{by:"word"}}` で単語ごとに0.4秒かけて下から出す
- 数字（#13）と締め（#18）だけは帯を使わず中央寄せ。#18 は影 `blur:26` で抜く

レンダーは `{ bitrate: 12000000, shards: 1, concurrency: 1, accel: "cpu" }`。
shards や concurrency を増やすと `ConsumerStalled` で落ちる。

### ロゴマーク（SVGパスで描いている・生成ではない）

社名の左に置くマークは、右に傾いた3本のバーが階段状に伸びる形。
ネイビー2本＋最長の1本をスチールブルー `#2e6ea8` にして、上昇を色でも見せる。

```
MARK_A = "M 0 118 L 28 118 L 44 64 L 16 64 Z  M 46 118 L 74 118 L 90 32 L 62 32 Z"
MARK_B = "M 90 118 L 118 118 L 134 0 L 106 0 Z"
```

**`path` の `width` / `height` はパスを拡大しない。**ボックスを決めるだけなので、
`d` は最終的なピクセル寸法で書くこと（拡大されると思って小さく書くと豆粒になる）。
塗りの指定は **`fill`**。`color` は通らず「a path with neither draws nothing」で落ちる。

出現はディゾルブ。社名が1文字ずつ出そろってから、
ネイビー2本が local 0.9秒から1.0秒かけて `opacity` 0→1、
スチール1本が0.25秒遅れて続く。`animate` の要素に **`at`** を書けば遅延できる。

実測値（レンダー結果をPILで数えた）：マーク x678–809 / 社名 x876–1227 /
間隔67px / 天地 y486–603 と y487–597。

### BGM（自前で合成している）

**Higgsfield の `generate_audio` は音楽に使えない。**スピーチ専用で、音楽モデル
（`sonilo_music`）はゲーム生成パイプライン専用と明記されており、単体利用は不可。
そこでサンドボックス内に numpy でシンセを書いて合成した（`bgm.py`）。

- **全部メジャーコード**。進行は Dadd9 → Aadd9 → Gmaj9 → Aadd9 の4小節ループ。
  初版は Bm7 を挟んでいたが、暗くなるので落とした。BPM 120 / 1小節2.0秒 / 29小節
- 音色：デチューンした鋸波のパッド、トライアングルのアルペジオ（1/16）、
  サイン＋鋸波のベース、スーパーソウのコードスタブ、
  オクターブ下のサインを重ねたリード、ピッチスイープのキック、クラップ、
  HPF後のノイズハット（裏拍にオープンハット）
- **盛り上げの仕掛け**：24–32秒にホワイトノイズのライザー → 32秒で全楽器が入る
  （「定着率92%」のカードとほぼ同時に当たる）。クラッシュは32秒・48秒・54秒
- **サイドチェイン**：キックのたびにパッド・ベース・スタブを0.38倍まで沈めて戻す。
  これがいちばん効く。入れないと音数を足しても団子になるだけで前に出ない
- フィルタは scipy が無いので **FFTで掛けている**（`rfft` → ロールオフを掛ける → `irfft`）。
  IIRをPythonループで回すと260万サンプルで遅すぎる
- リバーブはマルチタップディレイ＋LPF。最後に `tanh` で軽くサチュレーション

セクションごとの実測RMS（`bgm.py` が最後に出力する。一本調子でないことの確認用）：

| セクション | 秒 | RMS |
|---|---|---|
| イントロ | 0–8 | −29.8 dB |
| A1 | 8–16 | −21.8 dB |
| A2 | 16–24 | −16.7 dB |
| ビルド | 24–32 | −16.5 dB |
| **ドロップ** | 32–48 | **−14.0 dB** |
| ピーク | 48–54 | −13.6 dB |
| アウトロ | 54–59 | −15.2 dB |

**higgsedit には音声トラックを足す口が無い**（`do --list` の動詞に音声系が無い）ので、
映像を無音で書き出してから ffmpeg で多重化する：

```
ffmpeg -y -i renders/silent.mp4 -i bgm.wav \
  -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest renders/master.mp4
```

**営業上の利点：音源が完全オリジナルなので著作権処理が要らない。**
フリー音源のライセンス確認も年次更新も発生しない。

## 生成時の共通指針（HDD解析の実測より）

- `locked-off camera, static tripod shot` を明記。動かすのは #10 #11 #12 #13 #17 #18 のみ
  （プロの実作はフィックスが手持ちの8倍）
- `off-center composition` を常に入れる（実作で左右対称はわずか3.6%）
- `no text, no logos`（テロップは編集で入れる／他社ロゴの映り込み防止）
- `metal fabrication` を明記（食品工場風になるのを防ぐ）
- 5秒で生成し、編集で1.5〜4秒に詰める（AIは冒頭が不安定）

## 金額の根拠（提案書用）

「実写の約半分」は**使わない**。実写60万に対し44万は73%で、稟議で計算されると崩れる。

| 社員の拘束 | 出演者・立会い含め半日〜 | **なし** |
| 撮影日の調整 | 必要 | 不要 |
| 出演者の退職・異動時 | **撮り直し** | 差し替え不要 |
| 設備更新時 | 全編撮り直し | 該当カットのみ差し替え |

稟議に書く一文：
> 制作費で16万円、撮影によるライン停止を含めるとそれ以上の差が出ます。
> 撮影日を設けないため、現業を一切止めません。

ロープレで最も刺さったのは「工場を止めない」。先方は「半日止めると数十万の
損失」と言った。**この一行を最初に出すこと。**

## ロープレで出た反論と、効いた返し

| 反論 | 効いた返し |
|---|---|
| 社員じゃない人が出るのは？ | 退職・異動で差し替えが要らない。個人情報を出さずに済む。顔出しを嫌がる社員に無理をさせない |

| 何年でも使える？ | 言い過ぎ。「**人の入れ替わりでは差し替え不要**」に絞る。設備更新時は**該当カットのみ**作り直せる |
