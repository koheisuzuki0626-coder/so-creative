## 0. 埋める前に決めたこと【社内のみ】

1. **視聴者と、見た後にしてほしいこと**
   前半＝若手求職者（採用サイトで見る）／後半＝企業担当者（展示会で見る）。
   求職者には**応募**、企業担当者には**問い合わせ**。
2. **ナレーションの有無** → **無し。**テロップとBGMで語る。
   理由：展示会のモニターは無音で流す。音に依存すると後半の用途で死ぬ。
3. **原稿を先に確定** → ナレーションが無いので、**テロップ6枚の文言を先に確定**させた。
   これがカットの区切りになる。
4. テロップ1枚につき1カットを割り当て、間を映像で埋めた。
5. そのあとカット表。

**ここでひな形との食い違いが1つ出た。**ひな形 3 の表は「ナレーション無し＝
1.5〜2.3秒」だが、この案件の平均は **3.1秒**（59秒 ÷ 19カット）。
**テロップを読ませる時間が要るため。**→ ひな形の 3 に帯を足した（2026-09-24）。

## 2. 設計方針【社外OK】

- **カットの長さ**：**3秒前後**を基本にします。テロップを出すカットだけ
  4秒前後に伸ばし、**読み切れる時間**を確保します
- **テロップ**：画面下部に位置を固定し、**要点だけ6枚**。1枚 10〜20字。
  **音を切っても内容が伝わる**設計です（展示会は無音再生のため）
- **音**：ナレーションは入れません。**BGMのみ**。
  楽曲はこちらで**オリジナルで制作**するので、**著作権の処理と年次更新が不要**です
- **冒頭3秒**：朝の工場と、動き出す加工機。「どこの・何の会社か」を
  ロゴではなく**現場の絵**で出します
- **締め**：働く人の正面カット →「堅実に、まっすぐに。」→ ロゴと採用サイトURL

### 尺の使い分けのご提案【社外OK】

> 同じ素材から **60秒のフル版と15秒の展示会版**を書き出せます。
> 採用サイトには前者、展示会モニターには後者（**無音・ループ**）。
> 15秒版は本編の確定後に着手するので、**追加は本編の3割ほど**で収まります。

## 5. AIで作れない＝素材をお願いするもの【社内のみ・判定用】

| 当たるもの | この案件での扱い |
|---|---|
| 企業ロゴ・社名の文字（#19） | ロゴデータをお預かり。社名はSVGで組む（生成しない） |
| 実在しない設備を描く事故 | **設備一覧を必ずもらう。**ロボット・コンベア・自動倉庫は無かった |
| 珍しい機械（ワイヤーカット・#5） | 静止画で形を確定 →`start_image` で動画化。先方の写真があればそれが最善 |
| 定着率などの数字（#13） | **先方の実数と出典。**率だけだと盛って見えるので実数を併記 |
| 他社ロゴの映り込み | プロンプトで明示的に禁止。生成後に目視 |
| 社員の証言 | 今回は使わない（イメージ映像と明記する設計） |
