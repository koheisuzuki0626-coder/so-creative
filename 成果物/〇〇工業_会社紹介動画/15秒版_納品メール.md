## 残した判断

**軽量版は請求しない。**
納品メールで「軽量版が必要でしたらお申し付けください」と書いた以上、
ここで追加費用を取ると信用を損なう。作業は数分。
**自分で出した申し出は、請求しないところまでが申し出。**

**解像度は落とさない。**
「軽くしてほしい」と言われても、いきなり 720p にしない。
ビットレートを下げれば 1080p のまま6分の1になる。
**先に解像度を落とすと、後から「思ったより粗い」と言われて戻すことになる。**

**faststart を必ず付ける。**
`-movflags +faststart`。これがないとWeb埋め込みで
「全部落ちきるまで再生が始まらない」。サイトに載せる動画では必須。

## 書き出しコマンド

```
ffmpeg -i 納品版.mp4 \
  -c:v libx264 -preset slow -crf 23 -maxrate 3500k -bufsize 7000k \
  -pix_fmt yuv420p -profile:v high -level 4.0 \
  -c:a aac -b:a 128k -ar 48000 \
  -movflags +faststart 軽量版.mp4
```

87.5MB → 14.2MB。**SSIM 平均 0.9912 / 最小 0.9761。**
いちばん落ちるのは28秒付近（切粉が飛ぶカット）だが、並べても差は分からない。
