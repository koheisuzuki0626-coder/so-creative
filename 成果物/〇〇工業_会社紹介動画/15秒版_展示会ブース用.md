## 前提：本編を15秒に詰めてはいけない

| | 本編（60秒） | 15秒版 |
|---|---|---|
| 観客 | **求職者** | **取引先候補** |
| 視聴環境 | 手元・PC | 55インチを2〜3m離れて |
| 音 | BGMあり | **音を出せない**（主催者が禁止） |
| 見られ方 | 頭から通して | **通路沿い・途中から・ループ** |

**メッセージを入れ替える。**

## 文字サイズは計算で決める

55インチ16:9の横幅は約1218mm。1920pxなので **1px ≒ 0.634mm**。

| | px | 画面上 | 3m先の視角 |
|---|---|---|---|
| 本編のテロップ | 54 | 34mm | 32分 |
| **15秒版のテロップ** | **110** | **70mm** | **80分** |

通常の読書が15〜20分。**歩いている人が一瞥で取るには本編の大きさでは足りない。**

### テロップの狙い

**① 工程を、分けません。**
本編のA案と同じ事実だが、発注側には別の意味を持つ。
**窓口が一貫している＝受け渡しのミスが起きない、話が早い。**

**② ワイヤーカットも社内で。**
外注が挟まらない＝**納期の話**。社長の思い入れのある設備が、そのまま営業の武器になる。

**③ 小ロットこそ、ご相談を。**
ブースでの行動喚起。**ただし小ロット対応の可否を確認していない。**
未確認の能力を謳うのは、初稿で定着率を仮置きしたのと同じ危険がある。
確認が取れなければ「まずはお気軽にお声がけください」に差し替える（テキストのみの変更）。

## ループ設計

**「頭と尻の画をつなげる」という当初案は捨てた。**それだと冒頭に動きの強い画を置けず、
通路を歩く人の視界に引っかからない。代わりに2つを組み合わせた。

**1. 両端を純白にする。**尻は白いロゴカードで終わり、頭は白からディゾルブで始まる。
最終フレームと先頭フレームがどちらも「純白＋右下ロゴ」の同じ絵になるので、継ぎ目が消える。

**2. 右下に常時ロゴを出す。**途中から見た人がどこの会社か分かるようにするには、
頭と尻に社名を置くより**ずっと出しておく方が確実**。

### 実測で確認した

| | 平均輝度(YAVG) |
|---|---|
| 最終フレーム | 234.621 |
| 先頭フレーム | 234.621 |
| **差分画像** | **0.006**（0.002%） |

**234.6 は BT.709 のリミテッドレンジ（16〜235）で白の最大値。**フルレンジの255と
比べて「白くない」と誤読しないこと。最初の版では 228 対 235 で差が出ていた
（フェードが15.0秒ちょうどで完了する設計だったため、最終フレームが白くなりきっていなかった）。
**両端に純白の静止を数フレーム挟んで解決した。**

## ハマったところ

### compose() は trackIndex を受け取らない

CLIの `higgsedit do <dir> compose --help` には `--trackIndex` があるが、
**JSX側の `p.compose(nodes, options)` は読まない。**`cli.mjs` の実装は
`at` / `dur` / `camera` / `name` しか見ていない。

レーンは `assignLane(laneEnds, at, end)` が **lane 1 から順に空きを探して**割り当てる。
つまり**書く順番が唯一の制御手段。**

白のオーバーレイをテロップより後ろに書いたら、
`compose: [0.18s, 0.68s] overlaps clip (...) on track 1` で落ちた。
**先に書くと下のレーンに入り、テロップと常時ロゴがその上に載る。**

結果として、白の上に常時ロゴが乗る。両端とも同じ絵になるので、むしろ都合がよい。

### 免責表記が読めなかった

ロゴカードの背景はグレーのグラデーション。`#8a8a8a` ではコントラストが足りず、
2〜3m離れたら見えない。**明記した意味がなくなる。**

`#4f4f4f` ・32px・太字にした。

### 無音でもオーディオトラックは入れる

音は鳴らさないが、**音声トラックのないファイルを受け付けない再生機がある。**

```
ffmpeg -i silent.mp4 -f lavfi -i anullsrc=r=48000:cl=stereo \
  -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 96k -shortest master.mp4
```

## 営業用の15秒版について（展示会後）

社長から「15秒版が良ければ営業でも使いたい」と打診あり。

**同じ15秒でも中身が別物になる。**先に伝えてある。

- 音が出せる環境 → BGMを使える
- 相手が座って見る → ループ不要、文字を大きくする必要もない
- 商談の文脈 → 行動喚起ではなく、具体的な実績や対応範囲

**「同じ尺だから安くできますよね」を先に潰してある。**
値段は展示会後に別途相談。
