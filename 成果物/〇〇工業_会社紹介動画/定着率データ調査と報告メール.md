# 定着率の比較データ：調査結果と報告メール

**製造業の求人動画で「定着率◯%」を出すとき、そのまま使える。**
案件が変わっても効くので、数字だけ差し替えて使い回すこと。

## 発端

初稿で「入社3年後の定着率 ◯◯%」のテロップを仮の92%で出した。
実数は **78%** と判明。単独で出すと平凡なので
**「業界平均と並べる」**ことを提案したところ、先方から
「調べたら製造業の平均は8割ほどらしく、78%は平均以下では」と指摘された。

**自分の提案が崩れかけた。**約束どおり調べ直した結果が以下。

## 一次データ

厚生労働省「新規学卒就職者の離職状況（**令和4年3月卒業者**）」
令和7年10月24日公表。別紙2（高卒）／別紙3（大卒）。

- 報道発表 https://www.mhlw.go.jp/stf/houdou/0000177553_00010.html
- 別紙2（高卒）https://www.mhlw.go.jp/content/11805001/001318972.pdf
- 別紙3（大卒）https://www.mhlw.go.jp/content/11805001/001318973.pdf

**公表されているのは離職率。**以下は 100 − 離職率 で定着率に直したもの。

### 事業所規模別・就職後3年以内の定着率

| 事業所規模 | 高卒 | 大卒 |
|---|---|---|
| 5人未満 | 36.8% | 42.5% |
| 5〜29人 | 45.4% | 48.0% |
| **30〜99人** | **54.8%** | **58.1%** |
| 100〜499人 | 63.3% | 66.1% |
| 500〜999人 | 70.1% | 68.5% |
| 1,000人以上 | 73.7% | 73.0% |

### 産業別・就職後3年以内の定着率

| | 高卒 | 大卒 |
|---|---|---|
| 調査産業計 | 62.1% | 66.2% |
| **製造業** | 71.4% | **78.8%** |

（参考・離職率のまま：調査産業計 高卒37.9% / 大卒33.8%、製造業 高卒28.6% / 大卒21.2%）

## 結論

**① 産業の軸では負ける。**大卒×製造業の定着率は **78.8%**。
78%はこれをわずかに下回る。**比較に出した瞬間「平均以下」になる。**

**② 規模の軸では全区分に勝つ。**78%は、**1,000人以上の大企業の平均
（高卒73.7% / 大卒73.0%）すら上回る。**町工場の規模（30〜99人＝54.8%）とは
23ポイント以上の差。

**③ この結果は頑健。**どの規模区分に当てはまっても78%は平均を上回るので、
**先方の人数が分かる前に方針を確定できる。**回答待ちで制作が止まらない。

> **同じ78%が、軸を変えるだけで真逆の意味になる。**
> 誇張ではなく、公的統計のままの読み方。数字は変えず、比較対象を選ぶ。

## 注意点

- **厚労省の統計は新規学卒者に限定。**先方の78%が中途採用を含む全社員の
  数字だと比較対象がずれる。**必ず確認する**
- 統計の区分は企業規模ではなく **事業所規模**。画面の文言も
  「同規模の会社」ではなく「**同規模の事業所**」とする
- 高卒と大卒で平均が違う（54.8% / 58.1%）。どちらと並べるか要確認
- **規模別×産業別のクロス集計は公表されていない。**
  「製造業かつ30〜99人の平均」は出せない。規模だけで比較する

## このメールの設計

**① 自分の間違いを最初に認める。**
隠して別の軸にすり替えると、後で気づかれたときに全部が疑われる。
先に認めると、後半の提案の信頼度が上がる。

**② 社長がそのまま読める形にする。**
このメールは転送される。結論・表・出典が揃っていて、
担当者が説明を足さなくても通る構成にする。

**③ 人に言いたくなる数字を1つ作る。**
本題は同規模との比較だが、「大企業の平均すら上回る」の一行があると社内で話題になる。
**社長が人に言いたくなる数字**を作っておくと、企画が前に進む。

**④ 質問はするが「待たなくていい」と書く。**
3つ質問すると普通はそこで止まる。「どの区分でも勝つので方針は確定」と書いて、
回答待ちで第2稿が止まるのを防ぐ。

## 手順のメモ（次回の調査用）

厚労省のPDFは `WebFetch` ではテキスト抽出できない（バイナリのまま返る）。
ただし**ローカルに保存されている**ので、pypdf で自分で開ける。

```
~/so-portfolio/discord-groupchat/venv/bin/python3 -c "
from pypdf import PdfReader
print(PdfReader('保存されたパス.pdf').pages[0].extract_text())"
```

グラフのPDFは**ラベルと数値が別々に並んで**出てくる。系列の順番は凡例の
テキスト順とは一致しないので、**既知の値（全体の離職率など）と突き合わせて
どちらの年かを確定させること。**今回も第1系列が令和3年、第2系列が令和4年だった。
