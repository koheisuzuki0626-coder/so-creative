# いくらで受注できるか（2026-09-21）

**取り方**：実際に売られている価格だけを見る。
- **ココナラの実出品** … 価格に**販売実績の件数**が付く＝実際に売れた証拠
- **制作会社が自社サイトに出している料金表** … その会社の値段であって、相場ではない

**使わなかったもの**：アイミツ・動画幹事・むびる等の「相場まとめ記事」。
一括見積もりサイトの集客記事で、幅を広く取った数字。出どころも母数もない。
9/19 までの調査はここから組み立てていた（だから検算できなかった）。

## 読み取れること

**① 60秒 ¥300,000 は「高い」ではなく「同額」。ただし相手は実績4,000社。**
同じ値段で、無料修正無制限・プロナレーション込みの会社がいる。
so. の実績は0件。**同額では選ばれない。**

**①-3（9/21 追記）実在の入札に置くと、so. は12社中5位（15秒×5本のとき）。**
落札した ¥333,000 との差は約20万円。**倍半分ではなく、詰められる差。**
そして落札した有限会社プラン・プロデュースも、同じ案件で
¥1,360,000 を入れた札幌映像プロダクションと**4.1倍**ひらいている。
**同じ仕様でも値段は1つに決まっていない。**so. が特別に高いのではない。

**①-2（9/21 追記）so. の価格帯そのものは、市場から外れていない。**
官公庁の落札額が ¥363,000〜366,300、制作会社の公開価格が 6〜60秒で
¥100,000〜300,000。**so. の梅60秒 ¥300,000・竹60秒 ¥384,000 はこの帯の中にある。**
ココナラ（¥30,000〜95,000）と比べると高く見えるが、あれは
**素材持ち込みの編集**が中心で、企画から作る仕事とは別物。
比べる相手を間違えると「so. は高すぎる」という誤った結論になる。
**価格の問題ではなく、実績0件の問題。**

**② 3分は完全に負けている。**
GJC は30〜180秒を**撮影込み**で¥300,000〜500,000。so. の梅3分は¥720,000。
ロードマップは P2 で「3分を売れるようにする」と置いているが、
**この帯はいちばん competitive が厳しい。**

**③ 「AI だから安い」という期待が市場にある。**
ココナラのAI出品は ¥5,000〜20,000 が中心。
so. は逆に「AIだが高い」側に立っている。**その理由を言えないと通らない。**

**④ 勝てる根拠は価格ではない。**

## 6. 「撮影なしの案件だけ」を探せるか（9/21）

「2件の違いが、そのまま so. の線引きになる」で、撮影があるかどうかで
so. の立ち位置が反転すると分かった。
では撮影なしの案件だけを拾えるか。**半分までしかできない。**

### 使える口｜官公需情報ポータル（中小企業庁）

`https://www.kkj.go.jp/api/?Query=動画制作` が XML を返す。
**鍵も登録も要らない**。国・自治体・独法の公告が横断で乗っている。

`scripts/bid-search.mjs` に落とした。やっていること：

1. 4つの語（動画制作 / 映像制作 / PR動画 / 広報動画）で叩く
2. 案件名が動画・映像に当たらないものを落とす（API の検索は緩く、
   「標識撤去業務」まで返ってくる）
3. 本文の語から撮影の有無を振り分ける
4. `--deep` でリンク先を開き、HTML の公告ページなら
   そこに貼られた仕様書 PDF まで辿って判定し直す

```
node scripts/bid-search.mjs --deep        # 撮影ありを除いて出す
node scripts/bid-search.mjs --deep --all  # 全部出す
```

PDF を読むには `pdfjs-dist` が要る（`npm i pdfjs-dist`、または
`PDFJS=...` で場所を指定）。無ければ「PDF（要確認）」で返すだけ。
この repo に package.json は置かない方針なので、必要なときだけ入れる。

### 実際に回した結果（2026-09-21）

**4語あわせて、動画の案件は14件しかなかった。** 内訳：

| 判定 | 件数 | 中身 |
| --- | --- | --- |
| 撮影あり | 2 | 千葉県リカレント講座（仕様書に「撮影」）、千葉県 海と夕陽 |
| なしの可能性 | 1 | 岐阜県 SDGsワークスタイル（参加資格に「CG制作を含む」） |
| 不明 | 8 | 富山×2・松山市・金融庁・久米島町・隠岐の島町・幌延・防衛省 |
| 取得できず | 3 | 404 が2件、壊れた PDF が1件 |

撮影ありと判定できた2件は、**どちらも公告が HTML だった**案件。
仕様書 PDF まで辿れたから分かった。

### 分かった限界

- **撮影の有無はタイトルにも公告にも書かれない。** 仕様書を開いて初めて分かる
- 官公需ポータルが持っているリンクは**たいてい公告 PDF**で、仕様書ではない。
  公告が PDF だと、仕様書がどこにあるか分からない → 8件が「不明」のまま
- 「アニメーション」「CG」「イラスト」は**撮影がない証拠にならない**。
  岐阜県の案件は「CG制作を含む動画制作**及び広告出稿**」で、
  CG は参加資格の話だった（そして広告出稿は so. の仕事ではない）
- 落札結果は載らない。5章の落札額は別途 発注者のページから拾っている

### 結論

自動で絞れるのは「動画の案件14件」まで。
**そこから撮影なしを選ぶのは、仕様書を人が開く作業になる。**
月に十数件なら手で開ける量なので、道具としてはこれで足りる。

ただし **so. はまだ応札できない**（開業届と入札参加資格の登録が要る）。
いまは「どんな案件がいくらで出ているか」を掴むための道具として使う。

## 7. 入札参加資格の取り方（9/21）

> **手順そのものは `record.html` の「入札に出られるようにする」に移した**（2026-09-23）。
> 開業の週にスマホで開くものなので、markdown だと読めないため。
> ここには出どころと、要項から拾った原文を残す。


出典は公式の[申請書記入要項 令和7年11月版](https://www.p-portal.go.jp/pps-web-biz/geps-chotatujoho/resources/app/pdf/guide_yusojisan.pdf)（90ページ）。
相場まとめ記事ではなく、要項の記載そのもの。

### 2つある。別物

| | 相手 | 手続き |
| --- | --- | --- |
| 全省庁統一資格 | 国の全省庁・独法 | 1回取れば全省庁で有効 |
| 自治体の資格 | 都道府県・市町村 | **自治体ごとに個別申請**（定期受付は2年ごと、随時受付もある） |

so. が拾えた案件（国交省の事務所・防衛省・金融庁）は前者。
札幌市のような自治体案件は別途その自治体に申請する。

### 全省庁統一資格

- 申請先：調達ポータル →「統一資格審査申請」→「インターネットによる申請」
- **随時審査受付期間：令和7年2月1日〜令和10年3月10日**（定期審査は終了済み）
- 資格の有効期間：付与された時点から**令和10年3月31日**まで
- 申請そのものに手数料はない（かかるのは納税証明書の発行手数料、数百円）
- 通知：窓口審査後、ヘルプデスクに書面が届いてから**1週間前後**で発送
- 区分は「役務の提供等」の **(1) 広告・宣伝**
  — 要項の定義が「広告、宣伝、**番組制作、映画、ビデオ**、広報、イベント企画等」

### 個人の添付書類（要項の一覧そのまま）

1. 納税証明書その２（個人）【写】
   ※取得できない場合は「所得税及び復興特別所得税の申告に関する申出書」で代替可
2. 納税証明書（その３の２）【写】
3. 財務諸表1年分【写】＝ 青色申告決算書 または 確定申告書第1表
4. 開業届 ※**必須添付ではない**が「円滑な審査を行うために提出」と書かれている

### 決算がなくても申請できる

要項にこう書いてある。

> ※新設のため決算のない個人あるいは法人の場合、「新設のため決算書なし」とメモ書きし、
> 財務諸表の代わりとして提出してください。

**開業した直後でも通る設計になっている。** 1年分の確定申告を待つ必要はない。

### 等級は問題にならない

役務の提供等の等級と予定価格の範囲：

| 等級 | 予定価格 |
| --- | --- |
| A | 3,000万円以上 |
| B | 1,500万〜3,000万円 |
| C | 300万〜1,500万円 |
| **D** | **300万円未満** |

実績ゼロならDになるが、**so. の料金帯（9万〜30万）はまるごとDの範囲**。
さらに6章で拾った富山河川国道事務所のオープンカウンター案件は、公示にこう書いてある。

> 国土交通省競争参加資格（全省庁統一資格）を有し（**資格の種類・等級・地域・営業品目は問わない**）

**D等級でいい。** 見積書は「郵送等またはメールにより提出」「見積合わせは立会不要」で、
仕様書はGEPSから誰でもダウンロードできる。

### 電子証明書

電子入札・電子契約には電子証明書が要るが、調達ポータルの案内では
**個人事業主はマイナンバーカードで代替可**。ICカードを年1〜2万払って買う必要はない。
上の富山のようにメール見積りで完結する案件なら、そもそも不要。

### NJSS のような有料サービスは要らない

NJSS（うるる）は入札公告を集めて通知してくれる民間サービスで、
`scripts/bid-search.mjs` と同じ仕事をもっと広い範囲でやっている。
料金は公式サイトに載っていない（問い合わせ制・8日間の無料トライアルあり）が、
代理店が出している数字では**プラチナプランが月64,000円（1年契約）**。
松1本（30万）が年に2本消える額で、動画案件が月十数件の市場には重い。

なお検索に出てくる `njss-marketing.com` / `research.njss.info` の記事は
**NJSS が自社サービスに誘導するために書いているもの**。
「YouTubeリサーチの精度がわるい」で捨てた相場まとめ記事と同じ構造なので、
この章はそれらを使わず、要項PDFと公示PDFから取っている。

### so. の順番

1. **開業届を出す** ← いまここで止まっている（傷病手当金）
2. 統一資格を申請（ネット・無料・1週間前後）

全部1で止まっている。ただし1をクリアしたら2は速いので、開業と同時に動かせる。
