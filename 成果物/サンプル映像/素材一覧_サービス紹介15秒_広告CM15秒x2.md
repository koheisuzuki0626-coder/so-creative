## 残った妥協点（編集で処理する）

**02 C2：うなずく向きが同僚と逆。**同僚は画面左にいるが、女性は画面右を向いて
うなずく。方向を明示して2回生成しても変わらなかった（座り位置と椅子の向きから
モデルが自然な動きとして右を選ぶ）。左の男性を「別の同僚」と見れば矛盾しないので
そのまま採用した。気になるなら右側を使うクロップで左の男性を外せる。

**04 C2：割る動作がない。**開始フレームが既に割れた餃子なので、
「箸で持ち上げ→割る」ではなく「割れた餃子を持ち上げて汁が垂れる」になっている。
テロップ「肉汁、そのまま。」なら成立する。割りを見せるなら2カットに分ける。

## 編集時の注意

**素材は5.04秒。訴求Aの C1（0–6秒）と訴求Bの C1（5–11秒）が足りない。**
選択肢は3つ。
1. 秒数を 0–5 / 5–10 / 10–15 に詰める（テロップのタイミングも合わせる）
2. C1 を `setpts=1.2*PTS` でスローにして6秒に伸ばす。シズルのスローはCMの定石で、
   油の跳ねが遅くなるのは不自然に見えない
3. C1 を6秒で生成し直す（+54クレジット）

**2を推す。**画は既に良く、追加コストがゼロで、絵の意図（焼き目を見せる）が強まる。

イン点は、04 C1 は push-in が強めなので後半（1.5秒以降）、
04 C3 は箸の動きが決まる 1.5–5.0秒、02 C1 は顔を上げる 2.0秒以降を頭に置く。

### 動きの付け方（ここで1回はまった）

**`drawbox` の `x`/`w` は時間式を評価しない。**`enable` はタイムライン対応だが、
`x`/`w`/`h` の式に `t` が無く、一度しか評価されない。「ブロックが左から開く」を
`drawbox=w='...t...'` で書いたら、**全フレームで `t` が最大値扱いになり、
ブロックが常に全開・右端固定**という結果になった（白背景で測って判明）。

`overlay` の `x`/`y` は時間式が効く。そこで**ブロックと文字を別PNGにして、
どちらも同じ `y` 式で下から190px持ち上げる**形に変えた：

```
overlay=0:y='190*max(0,1-(t-ST)/0.34)'
```

ブロックは `ST` からフェードイン0.16秒、文字は0.13秒遅らせてフェードイン0.22秒。
**ブロックが下から入って、その上に文字が乗る**動きになる。

締めは帯を使わず中央寄せ＋`GaussianBlur(28)` の影を2枚重ね。
背景を黒オーバーレイで落とす（02は34%、04は29%）。

**架空の名前**：02 は「**そのまま日報**／現場の日報アプリ」（初稿の「現場ノート」は
却下。転記しない＝そのまま届く、という価値が名前に入る方を選んだ）、
04 は「こがね餃子／羽根つき 冷凍餃子」。`telop.py` 冒頭の定数で差し替えられる。
**04のロゴはマークを捨ててワードマークだけ。**餃子を小さい図形で描くと
どうしても「皿」に見えたため。02はチェックマーク（機能を表すので残した）。

訴求Bの締めは C2（箸の寄り）で中央に餃子が来るので、**ロゴだけ上（画面の26%）に
逃がした**（`04_logo_top.png`）。訴求Aの締めは C3 なので中央のまま。

## 素材の差し替え（第2稿）

**「餃子が動いていない」「家族の動きも少ない」への対応。**

| カット | 問題 | 対処 |
|---|---|---|
| 04 C1 フライパン | 油と湯気は動くが**餃子自体が静止**。seedance 2.5 は静止画を start_image にすると被写体を大きく動かさない（鍋を煽る指示を入れても油だけが動いた） | **モデルを `kling3_0` に変更**（pro / 8秒 / 無音）。餃子が滑って揺れ、カメラもドリーする |
| 04 C3 食卓 | 家族の動きが小さい（手を伸ばすだけ） | 動作を具体的に積んで再生成。子が口に運んで頬張る→父が食べる→母が笑う。動き量は**実測2.1倍**（フレーム間差分 2.42→5.19） |

**kling3_0 は seedance より安く、動きが強い。**5秒proで **8.75クレジット**（seedance 2.5 の
5秒1080pは45）。ただし出力が **1928×1076** で厳密な16:9ではないので、
`crop='min(iw,ih*16/9)':'min(ih,iw*9/16)'` でセンタークロップしてから 1920×1080 に合わせる。

**崩れ防止の指示が必要だった。**最初の3案は餃子が途中で消えて別の形で復活したり、
平らに崩れたりした。プロンプトに「4個の餃子は最後まで丸ごとのまま、焼き目と羽根を
保ち、変形・平坦化・溶解・崩壊・増殖・消失をしない」と**否定形を並べて固定**したら
8秒間保った。

**8秒で作れたのでスロー処理が不要になった。**訴求AのC1（6秒）は `setpts=1.2` で
伸ばす計画だったが、kling は3〜15秒を直接指定できるので8秒素材から6秒を切り出した。
複製フレームが無くなり、コマ落ち感も消えた。

## BGM（自前で合成。`bgm.py`）

Higgsfield の `generate_audio` は音楽に使えない（スピーチ専用）ので、
会社紹介と同じく numpy で合成した。**音源がオリジナルなので著作権処理が要らない。**

| | 02 | 04（A・B共通） |
|---|---|---|
| BPM | 80（1小節3.0秒×5） | 128（1小節1.875秒×8） |
| 進行 | D - A - G - A - D | D - A - G - A ×2 |
| 編成 | パッド＋アルペジオ＋薄いベース＋スタブ | ＋キック・クラップ・ハット・ライザー |
| 仕掛け | 12.4秒に小さなクラッシュ（ロゴに当てる） | 9.6秒からライザー→11.15秒でクラッシュ |

全部メジャーコード（会社紹介で Bm7 を挟んで暗くなった反省をそのまま踏襲）。
キックのたびにパッド・ベース・スタブを0.42倍まで沈めるサイドチェイン、
scipy が無いのでフィルタは FFT（`rfft` → ロールオフ → `irfft`）。

**訴求A・Bは同じ曲をそのまま使った。**構成案の「作り分けは最小にする」に従い、
テンポ違いも作っていない。

**低域の偏りで2回作り直した。**初版は 20–120Hz が 92.7%（キックとベースだけが
鳴っている状態）。キックを0.85→0.3、ベースを0.3→0.15に落とし、パッド・アルペジオ・
スタブを上げて最終 **51.7% / 36.9% / 2.8%**（20–120 / 120–500 / 500–2000Hz）。
02は 25.9% / 67.8% / 5.0%（パッド中心なので中低域寄りで正しい）。

**未確認：音は数値でバランスを取っただけで、実際の聞こえは検証していない。**
帯域比・RMS・ピークは測ったが、再生して聞く手段がこの環境にない。
一度スマホで通して聞いて、違和感があれば `bgm.py` のレベルを触るのが早い。

## 04 C1 の動き（低い角度をやめて俯瞰にした）

寄りの低い角度で3回作り直したが、そのたびに別の問題が出た。

| 版 | 画 | 問題 |
|---|---|---|
| 1 | seedance・油と湯気だけ | **餃子が動かない**（静止画起点だと被写体が動かない） |
| 2 | kling・煽る＋ドリー | 鍋が静止しているのに餃子だけが滑る＝**動きに理由がない** |
| 3 | kling・菜箸で整える | 動きの理由はできたが、**餃子が鍋の縁からはみ出す** |
| **4** | **kling・真俯瞰＋カメラ回転** | **採用** |

**低い角度そのものが原因だった。**鍋肌とほぼ水平から寄ると、餃子の上端が
鍋の縁より上に出て「はみ出して」見える。真俯瞰にすると鍋が全部フレームに入り、
はみ出しも、餃子を不自然に動かす必要もなくなった。

**俯瞰用に静止画から作り直した。**2案（真俯瞰／斜め45度）を出して真俯瞰を採用。
斜め45度は餃子が油に浮いて揚げ物のように見え、形も崩れていた。

- 6個を円形に並べ、**羽根つき**（1枚に繋がった羽根）にした。俯瞰では焼き面が
  見えないので、**焼き色は羽根の茶色で見せる**
- 動きはカメラのゆっくりした回転＋油の沸きと湯気。餃子は羽根で繋がっていて
  動かせないので、動きはカメラが作る
- 3案とも比べた結果、**菜箸を入れる案より回転の方が画として強い**
  （菜箸は羽根の縁を挟むだけで持ち上げきれず、動作が中途半端に見えた）

**未解決：C2（箸で割る）とC3（皿の餃子）は羽根なし。**厳密には同じ商品に見えない。
CMでは調理と食卓で見た目が変わるのは普通だが、揃えるなら C2・C3 も
羽根つきで作り直す（各45クレジット前後）。

## SE（効果音・自前で合成。`se.py`）

**Higgsfield では作れない。**`generate_audio` はスピーチ専用、SFXモデル
（`mirelo_text_to_audio`）はゲーム生成パイプライン専用と明記されていて単体では使えない。
BGMと同じく numpy で合成した。**人の声は作らない**（笑い声や会話は不自然になる）。
環境音とモノの音だけ。

| 素材 | 作り |
|---|---|
| 屋外の環境音 | ピンクノイズ（1/f）を900Hz LPF＋120Hz HPFで2層、ゆっくりした振幅変調 |
| 室内の空気感 | 420Hz LPFのピンクノイズ＋108Hzのうなり＋薄いヒス |
| **焼き音** | 1.5k〜9kHzに絞ったピンクノイズ＋**ランダムな位置・長さ・帯域のパチパチを56回** |
| タップ音 | 1.8kHz HPFのクリック＋190Hzのボディ、指数減衰 |
| 打鍵 | 2.6kHz HPFのクリック＋320Hzのボディ、間隔を0.09〜0.2秒でばらす |
| 食器・箸 | 倍音列（1 : 2.01 : 3.4 : 5.2）＋高域ノイズ、減衰26 |
| 汁が落ちる | 1500Hz→320Hzに下がるピッチスイープ |

配置はカットに合わせて区間で切り替え（境界は0.12秒クロスフェード）。
02 は C1にタップ2回（顔を上げる直前）、C2に打鍵8回と紙の音、C3に遠くの金属音。
04 は焼き音を主役に置き、箸のカットでは残り火程度に落として汁の音を1つ、
食卓では食器と箸を4つ。

**レベルは BGM との差で決めた**（聞いて判断できないので数値で）。

| 区間 | SE − BGM |
|---|---|
| 02 全体 | −9〜−13dB（環境音なので控えめが自然） |
| **04 焼き音のカット** | **−4.8dB**（シズルは主役なのでBGMとほぼ同等） |
| 04 箸・食卓 | −13〜−16dB |

**フィルタ後の正規化を忘れて1回やり直した。**初版はSEが −37dB でBGMより22dB下＝
ほぼ無音だった。`fft_filter` の HPF はピンクノイズ（低域優勢）の振幅を大きく削るので、
**各素材はフィルタ後にピーク正規化してからレベルを掛ける**必要がある。

## この環境で編集するときの注意

- `ffmpeg` は入っていない。`pip install imageio-ffmpeg` のバンドル版を使う：
  `/usr/local/lib/python3.11/dist-packages/imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2`
  （7.0.2 / x264・x265・mp3lame・freetype 有効、**drawtext と ffprobe は無い**）
- `loudnorm` は1パスだと精度が出ず、AAC変換でピークが 0.0dB に張り付いた。
  **2パス（`measured_*` を渡す）＋ `alimiter=limit=0.82` で −1.8dB まで収めた**
