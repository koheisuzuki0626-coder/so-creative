## 作り方の原則（生成の弱点を演出に変える）

**同じ2人の顔を4分24秒保つのは、AI動画で最も壊れやすい。**今日直した3カットは
「接触の因果関係」だったが、人物の同一性はそれより難しい。

対策はそのまま**思い出ムービーの作法**になる。

| やること | 理由（両方に効く） |
|---|---|
| **顔を正面から長く見せない** | 崩れにくい。見る人が自分を重ねられる |
| 後ろ姿・手元・横顔・影を多用 | 同上 |
| **年代は3つまで**（出会い／日常／いま） | 段階が増えるほど崩れる |
| 服と髪型を年代ごとに固定し、プロンプトにも書く | 参照画像だけだと揺れる（30秒版で確認済み） |
| 2人が**同じフレームに入る画を減らす** | 1人ずつなら保ちやすい。並ぶ画は要所だけに置く |

## 通し（案）

**軸**：出会い → 日常の積み重ね → いま。季節が一巡し、**264秒で0秒と同じ場所に戻る**。

| 秒 | 曲 | 画 | 年代 |
|---|---|---|---|
| 0–14 | イントロ | 誰もいない部屋。窓の光だけが動く | いま |
| 14–43 | 入る | 手元のアルバム。ページがめくれる／一枚の写真に寄る | ― |
| 43–57 | 上がる | **出会い**。駅のホーム。2人はまだ他人。すれ違う後ろ姿 | ① |
| 57–82 | 高止まり | 並んで歩く。影だけが先に重なる | ① |
| **82–92** | **ブレイク①** | 立ち止まる。手が触れる寸前で止まる | ① |
| 92–102 | 立ち上がり | 手を取る。走り出す | ① |
| 102–117 | 上がる | 季節が変わる。同じ道を何度も歩く | ①→② |
| 117–132 | さらに | 日常。台所、洗濯物、傘を分け合う | ② |
| **132–196** | **本体 64秒** | 積み重ね。同じ構図を季節違いで繰り返す（春→夏→秋→冬） | ② |
| **196–215** | **ブレイク②** | **一人になる画**。低域が抜けるのに合わせて静かになる | ② |
| **215–230** | **最大** | 再会。後ろから手を回す。顔は見せない | ③ |
| 230–240 | 落ちる | 2人で並んで座る。後ろ姿 | ③ |
| 240–254 | アウトロ | 窓辺。手だけが重なっている | ③ |
| 254–264 | 締め | **0秒と同じ無人の部屋**。光の角度だけが違う | いま |

**0秒と264秒を同じ構図にする。**一周したと分かると、4分24秒が1本の線になる。
いまの30秒版に足りなかったのはこれ。

**132–196（64秒）は「同じ構図の季節違い」で持たせる。**ここが最長かつ最も
難しい区間だが、同一構図の反復なら生成も安定し、見る側にも時間の経過が伝わる。

## 必要な素材

kling3_0 は3〜15秒。長い区間は複数本に割る。

| 区間 | 本数の目安 |
|---|---|
| 0–14 / 254–264 | 2（同じ構図・光違い） |
| 14–43 | 3 |
| 43–57 / 57–82 | 4 |
| 82–92 / 92–102 | 2 |
| 102–117 / 117–132 | 3 |
| **132–196** | **8**（季節4×2） |
| 196–215 / 215–230 | 4 |
| 230–240 / 240–254 | 2 |
| **合計** | **28本前後** |

**28本 × 16クレジット ＝ 448クレジット**（残高1,152）。
⚠️ 人物の同一性で撮り直しが出るので、**実際は1.5〜2倍を見込む**。

## 先に決めること

1. **2人の見た目**（年齢・髪型・服）。Reference Element で通すので最初に固める
2. **季節の順番**（春始まりか、出会いの季節から始めるか）
3. 顔をどこまで見せるか（上の原則では要所だけ）
