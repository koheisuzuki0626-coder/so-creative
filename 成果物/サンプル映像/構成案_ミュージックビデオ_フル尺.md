**2026-10-16 起案。いまの30秒版を全面的に作り直す。**

## なぜ作り直すか（本人の指摘）

> 今だとダンス動画にインサートが入ってるだけ

**時間が進んでいない。**踊り手が別の場所で踊る画を7回繰り返しているだけで、
10秒見た人が30秒見ても新しい情報が入らない。

## 題材

**男女の思い出ムービー。踊りは入れない。**
位置づけは**MVサンプルのまま**（9ジャンルは変えない。商品を増やす話ではない）。

### 枠組み（本人の案）

**裏で男性が写真をめくっていて、それが回想と繋がっている。**

めくっているのは**回想に出てくる本人**。自分と彼女の思い出を見返している。
現在（めくる手）と過去（回想）が、同じ1人の人物でつながる。

この枠組みは3つ同時に効く。

| | |
|---|---|
| **現在地が分かる** | 手に戻るたび「いま」に戻る。断片を並べても迷子にならない |
| **切る理由ができる** | 写真をめくったから場面が変わる。恣意的なカットが無くなる |
| **顔を出さずに済む** | めくる側は**手だけ**。AIで最も壊れる顔の同一性を構造で回避できる |
| **同じ人物を2回使わずに済む** | 現在の彼は手だけ。回想の彼は若い頃。
**同一人物を年齢差で揃える必要がない**（手だけなら保てる） |

アルバムはもともと断片の集まりなので、**場面がバラバラであることが正しくなる**。

### 締め（2026-10-16 決定）

**彼女はもう居ない。**最後の部屋のテーブルに置くカップは**1つ**。
それだけで示し、言葉でも字幕でも説明しない。

この決定で各場面の重さが変わる。

- **215–230（最大音量）が彼女の顔を見る唯一の場所**になる。ここまで後ろ姿と
  手元で通してきたぶん、正面が1回だけ来ると効く
- **186.5秒の喧嘩**は捨てない。摩擦のある記憶のほうが本物に見える
- 0秒の無人の部屋が、見終わってから意味を持つ。**カップが最初から1つ**

## 作り方

### 写真→回想の繋ぎは【合成】で作る。生成しない

1. 回想クリップの1フレーム目を取り出す
2. それを**アルバムの写真の位置に合成**する
3. その写真に寄っていき、画面いっぱいで**動き出す**

ffmpegで組める。生成に頼らないので破綻せず、クレジットも使わない。
**写真と回想が同じ画であることが保証される**のが最大の利点。

### 人物の同一性

同じ2人を4分24秒保つのはAI動画で最も壊れやすい。構造で回避する。

- 顔を正面から長く見せない。後ろ姿・手元・横顔・影・引き
- 年代は**3つまで**（出会い／日常／いま）
- 服と髪型を年代ごとに固定し、**プロンプトの文言にも書く**（参照だけだと揺れる）
- **引きの画を多めに**。顔が小さければ崩れても見えない
