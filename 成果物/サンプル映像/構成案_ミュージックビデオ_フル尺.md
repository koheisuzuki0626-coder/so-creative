## 作り方

### 写真→回想の繋ぎは【合成】で作る。生成しない

1. 回想クリップの1フレーム目を取り出す
2. それを**アルバムの写真の位置に合成**する
3. その写真に寄っていき、画面いっぱいで**動き出す**

ffmpegで組める。生成に頼らないので破綻せず、クレジットも使わない。
**写真と回想が同じ画であることが保証される**のが最大の利点。

### 人物の同一性

同じ2人を4分24秒保つのはAI動画で最も壊れやすい。構造で回避する。

- 顔を正面から長く見せない。後ろ姿・手元・横顔・影・引き

**「顔を一度も見せない」ではない（2026-10-16に改めた）。**厳格に守ると全カットが
手元・後ろ姿になり、本人から「ある程度シチュエーション変えないと」と差し戻された
原因そのものになる。禁じるのは**種類**であって回数ではない：

| | 中盤で出してよいか |
|---|---|
| 横顔・相手を見ている・画面内で小さい | **可**（回想③の味見で実際に出た。表情がカットの価値になった） |
| 正面・カメラ目線・顔が大きい | **215–230秒だけ** |

回想③は指示に反して彼女が振り向いたが、参照画像と同一人物のまま崩れず、
しかもその表情が一番良かったので採用した。**種類が違えば食い合わない。**
- 年代は**3つまで**（出会い／日常／いま）
- 服と髪型を年代ごとに固定し、**プロンプトの文言にも書く**（参照だけだと揺れる）
- **引きの画を多めに**。顔が小さければ崩れても見えない

## カラコレ（2026-10-18 追加）

**淡い映画っぽい質感に振った。**生成し直しではなく ffmpeg のカーブで焼いている。
`scripts/mv_grade.py`（`--check` で持ち上げ量の割り当てだけ出る）。

| | 値 |
|---|---|
| 黒の持ち上げ | R 0.105 / G 0.095 / B 0.145（**カットごとに ×0.40〜1.00**） |
| 中間 | R 0.545 / G 0.505 / B 0.475（ハイライトを黄、シャドウを青へ） |
| ハイライト | R 0.955 / G 0.925 / B 0.885 |
| 彩度・コントラスト | 0.76 / 0.92 |
| 粒子 | `noise=alls=7:allf=t` |

### 持ち上げをカットごとに変えた理由

**輝度が7倍以上ひらいていた。**実測で 20.8（誕生日）〜177.7（海沿いの2人乗り）。
明るい側に合わせた持ち上げをそのまま当てると、暗いカットが濁る。

輝度110以上で等倍、30以下で0.40倍、あいだは直線で割り当てた。

| 持ち上げ | カット |
|---|---|
| ×1.00 | 足元・引っ越し・海沿い・自転車ヨリ・知らない街・彼女ヨリ雨・朝の台所・★正面 |
| ×0.6〜0.97 | 出会い・金魚・部屋・夏祭り・雨2人・喧嘩・冬の駅・ラスト |
| ×0.40〜0.5 | 花火・川面・誕生日・彼ヨリ笑み・喧嘩のあと・夏の帰り道・秋の料理 |

⚠️ **色味（中間・ハイライト・彩度・コントラスト）はカット間で揃えること。**
ここまでカットごとに変えると、切り替わるたびに色が飛ぶ。

### 試して捨てた案

| | 結果 |
|---|---|
| A マット（持ち上げ＋脱色だけ） | いちばん淡いが、**ラストの部屋が黄色く濁った** |
| C 青緑シャドウ | 雨と海は締まるが、**淡さが出ない**。狙いから外れた |
| **B 暖かいフィルム** | **採用。**海の空が白け、思い出ムービーの体温が上がる |

### ⚠️ カットごとに書き出して concat してはいけない

一度その作りで焼いたら **3フレームずれた**。`-ss` / `-t` がフレーム境界に
丸められ、29カットぶん積もる。★最大音量は215.0秒ちょうど（**6450フレーム目**）に
置く約束なので、`trim` を**フレーム番号**で指定して1パスで焼くこと。
