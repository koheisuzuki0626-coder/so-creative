# 構成案｜09 ミュージックビデオ（フル尺 4分24秒）

**2026-10-16 起案。いまの30秒版を全面的に作り直す。**

## なぜ作り直すか（本人の指摘）

> 今だとダンス動画にインサートが入ってるだけ

そのとおりで、**時間が進んでいない**。踊り手が別の場所で踊る画を7回
繰り返しているだけなので、10秒見た人が30秒見ても新しい情報が入らない。
インサートは質感を足しているだけで、話を前に進めていない。

## 曲（実測）

新しい音源。**264.000秒（4分24秒）**。

⚠️ **拍が立っていない。**BPM候補を70〜185まで0.05刻みで総当たりしたが、
どのテンポでも拍の位置にアタックが集まらなかった（最高スコア0.062、
ほぼ横並び）。打ち込みではなく音が持続する作り。

**これは編集方針を決める。**小節で等間隔に割ると、映像だけが律儀に動いて
曲から浮く。代わりに**曲が変わる瞬間で切る**。幸い、変化点ははっきり出た。

## 方針

**撮影ではできない画を軸に、時間の進行を下敷きに敷く。**

このMVの役目は「so-creative に頼むと何ができるか」を見せること。いまの版が
示せているのは「同じ人物を同じ世界で通せる」——AI動画では難しい部類だが、
**見た人には伝わらない**。普通のMVに見えるので。

**撮影では不可能な画が入ると、営業先が「これはAIでしかできない」と自分で
気づく。**価格表の説得力に直結する。

ただし不可能な画だけだと散るので、**時間と場所が一方向に進む**のを下敷きに敷く。

## 通し（案）

**軸**：日没 → 夜 → 深夜 → 夜明け。踊り手は1人。場所は地上から上へ上がっていく。

| 秒 | 曲 | 画 | 仕掛け |
|---|---|---|---|
| 0–14 | イントロ | 誰もいない夕方の交差点。信号だけが変わる | 静止に近い。人はまだ出ない |
| 14–43 | 入る | 踊り手が歩き出す。日が落ちていく | **空の時間が早回し**。歩く速度は等速 |
| 43–57 | 上がる | 路地。ネオンが点き始める | 看板の文字が**点くたびに違う言語**になる |
| 57–82 | 高止まり | 歩道橋。車の光跡 | 光跡だけが**逆再生** |
| **82–92** | **ブレイク①** | 立ち止まる。無音に近い | **周りの街だけが止まり、踊り手だけ動く** |
| 92–102 | 立ち上がり | 地下道へ降りる | 降りるほど**壁のタイルが水面になる** |
| 102–117 | 上がる | 地下の広い空間で踊る | 床の反射像が**本人と違う動きをする** |
| 117–132 | さらに | 階段を駆け上がる | 一段ごとに**季節が変わる**（雨→雪→花） |
| **132–196** | **本体 64秒** | 屋上。街を背に踊る | **街の高さが呼吸する**。ビルが伸び縮み |
| **196–215** | **ブレイク②** | 空に浮く。低域が抜けるのに合わせて重力が消える | **重力の消失**。髪とスカートだけ落ちない |
| **215–230** | **ラスサビ** | 最大。街全体が踊り手と同じ動きをする | **街が同期する**。窓の灯りが振りに合わせて点滅 |
| 230–240 | 落ちる | ゆっくり降りてくる | 浮遊から着地 |
| 240–254 | アウトロ | 夜明けの交差点。0秒と同じ場所 | **同じ構図に戻る**。ただし空が白い |
| 254–264 | 締め | 踊り手は居ない。信号だけが変わる | 0秒とまったく同じ画で終わる |

**0秒と264秒を同じ構図にする。**一周して戻ったことが分かると、4分24秒が
1本の線になる。いまの版に足りなかったのはこれ。

## 必要な素材

64秒の区間（132–196）が最長。kling3_0 は3〜15秒なので、**1本では持たない**。
区間ごとに複数本を生成して割る。

| 区間 | 必要本数の目安 |
|---|---|
| 0–14 / 254–264 | 同じ構図なので**1本を使い回す**（時間帯だけ変える＝2本） |
| 14–43 | 3本 |
| 43–57 / 57–82 | 4本 |
| 82–92 / 92–102 | 2本 |
| 102–117 / 117–132 | 3本 |
| **132–196** | **6本**（最長区間。寄り引きで割る） |
| 196–215 / 215–230 | 4本 |
| 230–240 / 240–254 | 2本 |
| **合計** | **26本前後** |

**26本 × 16クレジット ＝ 416クレジット**（残高1,152）。

## 先に決めること

1. **踊り手**（見た目・衣装・人数）。同じ人物を通すので最初に固める
2. **街の性格**（日本の都市か、無国籍か）
3. 上の「仕掛け」のうち、**どれを採ってどれを捨てるか**。全部入れると散る

## 前の版から引き継ぐこと

- Reference Element で同じ人物を通す（30秒版で機能していた）
- 衣装はプロンプトの文言でも固定する（参照だけだと揺れる）
- 暗い素材なので階調は締めるだけに留める。彩度を上げるとネオンが濁る
- **元素材を必ず `keep_source.py` で残す**（30秒版は素材が消えて作り直せない）
