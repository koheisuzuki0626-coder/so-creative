# サンプル映像 構成案｜03 採用（3分・180秒）

15秒版（`03_recruit_15s`）を作ったあと「採用は3分尺がいい」との判断で作り直す。
**架空の題材**（01 会社紹介と同じ架空の製造業）。クライアント実績としては出さない。
**社名は出さない**（e2e が「架空クライアントの名前を出していない」を検査している）。

## なぜ3分か

15秒では「職場の空気」と「育つ環境」が入らない。採用映像は説明会で流したり
採用サイトに置いたりするので、実務的にも3分前後が多い。
**尺が10倍になると設計が別物になる**ことを、サンプル自体で見せられる。

## 15秒版の扱い

サイトのカードには1本だけ載せる作りなので、**3分版ができたら15秒版は外す**。
ファイルは残す（`03_recruit_15s_*`）。同じ素材で尺違いを作った記録として工数記録に残す。

## 人物の一貫性をどう作るか（今回の要点）

3分では同じ人物が何度も出る。**kling3_0 は `start_image` しか受けられず、
`image_references` で人物を引き継げない。**seedance の `omni_reference` は
引き継げるが45クレジット/生成で、36カットだと1,600を超えて残高が足りない。

**そこで静止画の段階で人物を揃える。**
`nano_banana_pro`（2クレジット/枚）は `image_references` を受けるので、
基準の顔を1枚作り、それを参照して各カットの静止画を作る。
その静止画を `start_image` として kling に渡せば、動画も揃う。

```
基準の顔（2クレジット）
  → 各カットの静止画に image_references で渡す（2クレジット/枚）
    → kling の start_image に渡す（8.79/本）
```

**登場人物は4人**（会社紹介の2人より増やす。3分あると2人では持たない）。

|---|---|---|---|

| C | 検査 | 30代女性 | 別工程。A と受け渡しがある |

## 音

**BGM は3分用に新しく組む。**02 の15秒版（BPM100・6小節）をループさせると
単調になる。会社紹介の59秒版と同じく、章に合わせて厚みを変える。

| 章 | 秒 | 音の設計 |
|---|---|---|
| 1 朝 | 0–20 | パッドとベルだけ。薄く入る |
| 2 仕事 | 20–68 | ベースとアルペジオが入る。淡々と |
| 3 人 | 68–128 | いちばん厚い。ベルのメロディを足す |
| 4 職場 | 128–160 | 一度落として、数字のカットで持ち上げる |
| 5 締め | 160–180 | 全部入り → 最後の外観でリリース |

**SE**：工場の機械音を通して敷き、カットごとに切粉・クーラント・ノギス・
足音・自販機・空調を置く。**インタビュー風のカット（17・19・22・25・34）は
機械音を下げる**（声が聞こえる想定の画なので、音数を減らして「話している」ことを示す）。

**ナレーションはなし。**社員の声はインタビュー字幕で出す。
実案件では松（ナレーション込み）で提案する想定だが、
サンプルでは梅・竹の見え方を示すため字幕のみにする。

## テロップ

2系統を使い分ける。**第4章の数字だけ白帯にして、事実だと分かるようにする。**

| 用途 | デザイン |
|---|---|
| 本文・インタビュー字幕 | 純白＋画面下部のグラデーション（02・15秒版と同じ） |
| 第4章の数字（27・28・29・30・31・32） | 白帯＋黒文字（07 と同じ系統、STEP番号なし） |

インタビュー字幕は**鍵カッコ付き**にして、ナレーションではなく本人の発言だと分かるようにする。

## 進め方

1. **基準の顔を4人ぶん作る**（A・B・C・D）。ここで顔が決まるので先に確認する
2. カットの静止画36枚。人物が出るカットは基準を `image_references` で渡す
3. 静止画を確認してから kling で動画化
4. BGM（3分）と SE（3分）を組む
5. つないでテロップを乗せ、書き出す

**1と2の間で一度止めて顔を確認する。**3分は後戻りが高くつくので、
人物が決まる前に36カット進めない。

### 静止画のうちに直した3枚

| # | 問題 | 直し方 |
|---|---|---|
| 32 勤務表 | 掲示板に**日本語らしき崩れた文字**がはっきり出た（角度で隠す指示が効かなかった） | 題材ごと変更。**タイムカードを差し込む手元**にして、文字が写る対象をなくした |
| 34 A が笑う | インタビューなのに背景が旋盤の真横で、他のインタビュー（17・19・22・25）と画作りが揃わず、締めで浮いた | **17 の画像を `image_references` に渡し**、同じ構図・同じ座り位置のまま表情だけ笑顔に |
| 23 定時で帰る | 顔が見えない引きで C だと分からず、私服にしたので直前の22と繋がらなかった | **作業着のまま振り返って手を振る**構図に。顔が見えて同一人物だと分かる |

**文字は「角度で隠す」より「写る対象をなくす」ほうが確実。**
掲示板・伝票・画面のように文字がある前提の被写体は、指示で消しきれない。
