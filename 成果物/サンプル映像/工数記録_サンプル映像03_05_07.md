## 振り返り

### 1. 長尺は「尺」ではなく「同時に開くレイヤー数 × 尺」で詰まる

3分×36カットに、テロップのPNGを44枚（本文＋下敷き）重ねて一度に流したら、
ffmpeg が **13.9GB**（搭載15GB）を使い切って40分進まなくなった。
`-loop 1 -t 180` を44本ぶん同時に展開していたのが原因。

**6カットずつ6章に分けて焼いてから連結**に変えたら **2.2GB** に収まり、
1章あたり2分・全体13分で通るようになった。絵は同じ。

```
render_silent() を build() から切り出し、chunk=6 で章ごとに焼いて
concat デマルチプレクサで -c copy 連結。テロップは章に収まるものだけ渡す
```

**「長い動画が作れない」ではなく「一度に重ねすぎている」。**
次に長尺をやるときは最初から章分割で組む。

### 2. 否定形だけの指示は、別の破綻を呼ぶ

| 指示 | 出てきたもの |
|---|---|
| 「商品名を写さない」 | 自販機の棚が**空っぽ**になった |
| 「タオルは畳まれていない」 | くすんだタオルが**床にこぼれた** |
| 「古びていない」 | 社員24人の会社が**大企業の工場**になった |

**否定は「そこを避ける」だけで、代わりに何を置くかは決めていない。**
直すときは毎回「否定」＋「あるべき状態」をセットで書き直した。

- 「商品名を写さない」＋「無地ラベルの缶とペットボトルがぎっしり並ぶ」
- 「畳まれていない」＋「まっさらな純白で清潔」「床にこぼれていない」
- 「古びていない」＋「広すぎない」「棚が何十列も並んでいない」

### 3. 参照画像で「変えない部分」を固定できる

自販機を直すとき、`image_references` に**直前に採用した画像**を渡して
「変えるのは自動販売機の中身だけ」と書いたら、部屋・家具・人物・光がそのまま残った。
撮り直しの範囲を1カット全体ではなく**カットの中の一部**に絞れる。

同じ手で、夕方の外観（33）と夜の外観（36）を朝の外観（01）と同じ建物にできた。
**建物・場所・人物の同一性は、テキストではなく参照画像で担保する。**

### 4. 合成音声の日本語は使えなかった

インタビュー5人ぶんの声を入れる依頼に対して、

1. `seed_audio`（太郎・Ken・Hana・Callum）→ カタコト
2. 4エンジン比較（seed_audio / MiniMax / ElevenLabs / Seed Speech）→ MiniMax が「まし」
3. MiniMax のまま男性6声・女性3声 → Cillian と Hana を採用
4. それでも不自然 → **声なしに決定**

原価は **4.80クレジット**（全体の0.7%）で済んだが、**工数は4往復ぶん**かかった。
引用はテロップで出ているので中身は欠けない。
声のwavと組み込みのコードは `scripts/vo/` と `voice_03_3min()` に残してある。

**この工程は、音を聴いて判断できる人に確認してもらわないと前に進まない。**
作る側が良し悪しを確認できない工程は、往復の回数が読めない。

### 5. 設定の指定漏れが解像度で出た

`kling3_0` の `mode` は既定が `std`。指定を落としたら **716×1284** で返ってきて、
他のカット（1076×1928）と並べたときだけ甘く見えた。`pro` で取り直して10クレジット捨てた。

**生成のパラメータは、出力の解像度を毎回測って確かめる。**
見た目では気づけない差が、並べると出る。

### 6. 3分は「構成の勝負」になる

15秒（02/04）で直したのは全部「見え方」と「音」だった。
3分では**構成そのもの**に指摘が来た。

| 指摘 | 中身 |
|---|---|
| 全体的に古い印象 | 36カット中9カットの**題材選び**（休憩室・食堂・ロッカー・タイムカード） |
| 名札のカットを差し替え | カット単位の**役割**（朝の章に何を置くか） |
| テロップが途中で切れている | **文字数**（1行に収まらない引用を2行に組み直した） |
| ラストカットの建屋が古い | **締めの画**が全体の印象を決める |

**短尺は見え方、長尺は構成。**見積のときに見るべき項目が違う。

### サイトの工数モデルへの影響

現行モデルは
`工数 = 3.0h + 0.15h × 倍率 × 秒数 + 1.5h × (本数−1) + 1.0h × ナレーション本数`。

3分（180秒）を梅で当てると `3.0 + 0.15×1.0×180 ＝ 30.0h`。
今回の経過4.5h（3本ぶん・確認待ち含まず）とは桁が違う。
ただし**実案件は打合せ・素材待ち・社内確認が乗る**ので、
この4.5hをそのままモデルに入れるべきではない。

反映を検討するのは次の2点。

- **原価は秒数比例ではない。**3分で3.03クレジット/秒、15秒で20.9。
  長尺ほど安い。料金表は工数モデルで決めているので価格は変えないが、
  **長尺の原価率は想定より低い**という事実は記録しておく
- **ナレーションのオプション（1本 ¥30,000／1.0h）は、日本語では成立しない。**
  今回、合成音声は4エンジン×9声を試して不採用にした。
  実案件で受けるなら**人のナレーターを手配する前提**で、
  原価と工数を置き直す必要がある。**サイトの記載は要確認**
