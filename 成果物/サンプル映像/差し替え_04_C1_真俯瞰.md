# 04 広告・CM｜C1素材（真俯瞰）の差し替え指示

**対象**：`04_c1_kling.mp4`。完成品では 1.58〜4.29 秒（C2・C3）に使われている。
**2026-10-15 に本人が「AIっぽい」と指摘した画。**

## なぜ差し替えるか（実物を拡大して特定した破綻）

| 破綻 | 中身 |
|---|---|
| **銀色のビーズが浮いている** | 羽根の上に鏡面反射する銀の球。油の泡なら透明か飴色で光が透ける。調理の場に存在しない物体 |
| **餃子が羽根に接地していない** | 輪郭と羽根の境界に焼き付いた部分がなく、**影も落ちていない**。切り抜いて置いたように見える |
| **羽根は焦げているのに餃子だけ生** | 皮がマットで白く粉っぽい。蒸し焼きなら半透明になって艶が出る。火の通り方が矛盾 |
| **羽根がレースでなく粒々** | 一様な粒の集合で、パン粉かクッキーの表面。真円で、縁が反り返っていない |

①〜③は物理的に説明がつかないので、構図の工夫では隠せない。

## ⚠️ 角度を変えないこと

真俯瞰は**4案目で、消去法で残ったもの**（`素材一覧_…md` の記録）。
低い角度は3回失敗している——**鍋肌とほぼ水平から寄ると、餃子の上端が鍋の縁より
上に出て「はみ出して」見える**。「斜め45度の寄りにする」は再発する。

## 設定（前回と同じ）

- モデル `kling3_0` / pro / **8秒** / 無音 → **8.75クレジット**（5秒pro。8秒は要確認）
- 出力は 1928×1076 なので
  `crop='min(iw,ih*16/9)':'min(ih,iw*9/16)'` でセンタークロップしてから 1920×1080
- 真俯瞰＋ゆっくりしたカメラ回転

## プロンプトに入れるもの

**肯定（この4つが今回の追加）**

- 餃子の底が羽根と一続きに焼き付き、**根元に濃い焼き色の帯**ができている
- 餃子の**影が羽根の上に落ちている**
- 皮は蒸し焼きで**半透明になり艶がある**（白くマットではない）
- 羽根は**薄いレース状で穴が開き、縁が反り返っている**

**否定（既存＋今回の追加）**

- 変形・平坦化・溶解・崩壊・増殖・消失をしない（**既存。8秒保たせるのに効いた**）
- **金属光沢の球・ビーズ・鏡面の粒を出さない**（今回の追加）
- 餃子を均一な粒や砂のような表面にしない（今回の追加）

## 確認の手順（作ったら必ず）

1. 等倍で**銀の球が無いこと**
2. 餃子の根元に**影と焼き色の帯があること**
3. 皮に**艶があること**
4. 8秒のあいだ**個数と形が変わらないこと**

## ついでに直すこと

C2とC3は**同じ素材の別区間**（`C1_IN` と `C1_IN+3.4`・1.35倍ズーム）で、
サイズがほとんど変わらないまま切っているので**ジャンプカットになっている**。
差し替えのときに **1カット（約2.4秒）に統合**する。`build.py` の該当2行を1行にする。
