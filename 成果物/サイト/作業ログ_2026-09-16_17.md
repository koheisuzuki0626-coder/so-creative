## つまずいた点（同じことを繰り返さないため）

- **成果物が作業ブランチにしか無いことがある。**`ナレーション原稿_60秒_2案.md` が
  そうだった（main に無く、GitHub を既定のまま開くと見えない）。
  `git -c core.quotepath=false ls-tree -r --name-only origin/<branch> -- 成果物/...`
  で両ブランチを突き合わせて確認する。日本語パスは既定だと8進エスケープされて
  `grep` に引っかからないので `core.quotepath=false` が要る
- **動画の版は、音声帯域（300–3400Hz）の平均で見分けられる。**
  `ffmpeg -i f.mp4 -map 0:a -af "highpass=f=300,lowpass=f=3400,volumedetect" -f null -`
  で出る `mean_volume` を比べる。区間を切って測れば、どこで喋っているかも分かる
  （`-ss 0 -t 3` のように）。ファイル名では判断しない
- **MD5 で照合する。**Drive から落としたものが納品物と同じかは
  `構成案と素材一覧.md` の表の MD5 と突き合わせる
- **ローカルの mp4 を信用しない。**`~/Downloads` にあったナレーション版は旧稿だった。
  最終版は Drive にある
- **ffmpeg の `drawtext` はこの環境に入っていない。**比較画像を作るときは
  `vstack` で並べるだけにする
