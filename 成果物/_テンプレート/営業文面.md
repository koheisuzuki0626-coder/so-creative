**送る前に2つ確認する。**

1. **開業届を出したか。**営業活動は労務にあたり、傷病手当金が止まる
   （2026-09-20・保険者に確認）。出す前に送ってはいけない
2. **前職で知った相手に送っていないか。**退職時の秘密保持誓約書で、
   前職の顧客の社名・住所・連絡先が秘密情報とされ、退職後も使用しないと誓約している
   （2026-09-23 に書面を確認）。**前職の取引先への営業はしない**

書いておくのは、開業した週にそのまま動けるようにするため。

## 設計

初回の目的は**受注ではなく返信をもらうこと**。だから、

- **短くする。**スマホで1画面。長いと読まれない
- **売り込まない。**「お困りではないですか」は相手に否定をさせる形なので使わない
- **こちらの近況として伝える。**相手が判断するのではなく、思い出してもらうのが先
- **具体物を1つだけ出す。**サンプルのURL。見れば分かるものを1本
- **小さく閉じる。**「見てみてください」で終える。日程調整を初回で求めない

## A. 前職の取引先 — **使わない**（2026-09-23 決定）

退職時の書面を確認した結果、**この経路は使えない**と判断した。

- 秘密保持誓約書で、**前職の顧客の社名・住所・連絡先が秘密情報**とされている
- それを「開示、漏洩もしくは**使用**しない」と誓約しており、**退職後も続く**
- 前職で知った相手に営業をかけるのは、この「使用」に当たる

競業避止の条項そのものは書面に無く、**同業で独立すること自体は問題ない**。
制限されるのは「前職で知った顧客情報を使うこと」。

**未確認が1つ残っている。**退職合意書に「就業規則のうち退職後の義務を定める部分は
引き続き効力を有する」とあり、**就業規則側に競業避止条項がある可能性**は消えていない。
就業規則の写しが出てきたら読む。出てこなければ、いまの行動範囲
（前職の顧客に触れない）を守っている限り問題は起きにくい。

**この判断はリポジトリに社名も条文も残さない。**退職合意書で
合意の存在と内容を第三者に開示しないことも約束しているため。

→ Q1 の主軸は **B（知人・友人からの紹介）**。
   紹介以外の経路は下の「ほかの経路」から Q2 までに1つ立てる。

## ほかの経路（A が使えないので、こちらが主軸）

前職の取引先は、確認が取れるまで数えない。**A を外しても成り立つ形**にしておく。

| 経路 | 制約 | 立ち上がり |
|---|---|---|
| **知人・友人の勤務先**（B の文面） | 前職と無関係なら問題なし | 早い。まずここ |
| **前々職の伝手**（東北新社・C3Film） | 年数が経っているぶん制約は薄い可能性。要確認 | 中 |
| **商工会議所・地域の交流会**（名古屋） | なし | 中。人に会う必要がある |
| **制作会社の下請け** | 前職と競合しない先なら | 早いが単価は落ちる。実績は積める |
| **サイト・YouTube からの流入** | なし | 遅い。ただし止まらない |

ロードマップの「受注経路をどれにするか」は**まだ決めていない**。
A が使えるかどうかで、ここの答えが変わる。

## 送るときの決めごと

| | |
|---|---|
| 1日に送る数 | **5通まで**。返信が来たときに丁寧に返せる量にする |
| 追いかけ | 1回だけ。2週間後に「その後いかがでしょうか」を1行。それ以上は追わない |
| 返信が来たら | **24時間以内に返す。**ここが一番の差になる |
| 断られたら | 「また機会があれば」で終える。理由を聞かない（聞かれると相手は面倒になる） |

## 書いてはいけないこと

- **前職の売上や実績の数字**（検証できない。サイトにも出していない）
- **前職の社名を持ち出しての信用づけ**（「〇〇を担当していました」は、
  相手が前職の取引先なら特に危ない。サイトの経歴も社名を伏せてある）
- **前職で知った会社への連絡**（顧客の社名・連絡先は秘密情報。上の A 参照）
- **「AI だから安い」**（安さで選ばれると、次も安さで比べられる）
- **できないことをできると書く**（4K・実在の商品・正確な文字は作れない）

## 料金の話は record.html にある（2026-09-23 に移した）

料金を聞かれたときの答え方と、金額を詰められたときの返し方は
**`record.html` の「営業で使う」**（第4幕）に移した。
営業中はスマホで開くので、markdown では読めないため。

- **料金を聞かれたときの答え方** … 「工数だからこの値段」とは言わない。
  想定質問5つ（なぜこの値段／登場人物／人数と手間／短い動画/ナレーション）
- **金額を詰められたときの返し方** … 値引きではなく構成で答える。
  構成で落とせる額、下げていい限界（梅は5〜6%しかない）、引く基準

**2か所に置かない。**数字がズレたときに片方だけ古くなる。
