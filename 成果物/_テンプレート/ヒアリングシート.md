# ヒアリングシート

打ち合わせをせず、**メールだけで着手できる状態にする**ためのシート。
口頭で聞いていたことを先に構造化して、**1往復で埋まる**ようにするのが目的。
これが無いまま打ち合わせをやめると、往復が増えて納期がそのぶん伸びる。

下の「お客様に送る本文」をそのままコピーしてメールに貼る。
`index.html` の料金シミュレーターが送るメール本文と同じ項目を含めてあるので、
計算機から来た問い合わせには、足りない項目だけを聞き直せばいい。

**必須は5つだけ。**残りは「分かれば」で聞く。
最初から全部を求めると返信が止まるので、埋まらなかったぶんは
構成案の中で提案してしまい、確認で拾う。

---

## お客様に送る本文（ここからコピー）

```
映像づくりの前に、いくつか教えてください。
分かる範囲で結構です。空欄があっても、こちらから提案いたします。

■ ここだけは教えてください

1. 会社名 / お名前：
2. 映像の用途（どこで、誰に見せますか）：
3. 届けたい相手（例：採用候補者、既存のお客様、社内）：
4. 参考にしたい映像・URL：
5. ご希望の公開時期：

■ 分かれば

6. 尺のイメージ（15秒 / 30秒 / 60秒 / 90秒 / 3分 など）：
7. 本数（1本 / 複数）：
8. 人物を出したいか（出す / 出さない / どちらでも）：
9. ナレーション（人の声 / AIの声 / 入れない / おまかせ）：
10. お渡しできる素材（ロゴ・写真・既存資料・入れたい文言）：
11. ご予算の目安：

──
4 の参考URLは、できれば2〜3本お願いします。
「かっこいい感じで」「明るい雰囲気で」は人によって指すものが違うので、
実物を見せていただくのが、いちばん早くて正確です。
YouTube や他社サイトの映像で構いません。
```

## 受け取ったら、so. が埋める

| | | 出どころ |
|---|---|---|
| 段 | 梅 / 竹 / 松 | 8（人物）と 9（ナレーション）から |
| 合計の尺 | 秒 | 6。無ければ 2 から逆算（下の表） |
| 本数 | 本 | 7 |
| ナレーション | なし / AI / 人物 | 9 |
| 概算金額 | ¥ | 料金シミュレーターに入れる |
| 納品予定日 | | 計算機が出す納期 ＋ 確認の往復 |
| 不足している項目 | | ← あれば**1通にまとめて**聞く |

**聞き直しは1通にまとめる。**2通、3通と分けると、そのたびに相手の返信待ちが挟まり、
往復の回数がそのまま納期に乗る。

## 尺が決まっていないとき

用途から当てる。提案として出し、構成案の確認で詰める。

| 用途 | 尺の目安 |
|---|---|
| SNS 投稿・広告 | 15〜30秒 |
| 会社紹介・サービス紹介 | 60〜90秒 |
| 採用・展示会 | 90秒〜3分 |
| 社内向け（手順・研修） | 15秒 × 複数本 |

## 先に伝えておくこと

聞くだけでなく、この3つは**こちらから先に言っておく**。
あとで出てくると、修正回数を食うか、断ることになる。

- **ロゴ**：映像に重ねるのはできる。**映像の中の物（看板・車体・パッケージ・名札）に
  入った状態をつくるのは苦手**。AI が細かい文字を正しく描けないため。
  その場合は無地のまま生成して、あとから重ねる
- **AI 生成であること**：人物はすべて AI。実在の人物には似せない
- **修正回数**：梅2回・竹3回・松3回まで無料。超えたぶんは別途見積り

## 揃ったら

1. 見積書（`見積書.md`）を出す
2. ご発注をいただいたら業務委託契約書（`業務委託契約書.md`）
3. 着手金の請求書（`請求書.md`）
4. 入金を確認してから制作に着手する

数字（着手金50%・期日・修正回数・キャンセルの按分）は
サイトの料金ページと3つのひな形に揃えてある。変えるときは全部まとめて。
