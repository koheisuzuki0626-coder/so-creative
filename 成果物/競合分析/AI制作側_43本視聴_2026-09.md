## 3. 制作日数の推定

「生成AIに慣れた人なら何日で作れるか」の推定：**中央値 2.2日**（1〜5日・40件）。

自分の工数モデル（`assets/pricing.js`：3.0h ＋ 0.15h×段係数×秒数）で
60秒・竹を計算すると **14.0時間 ≒ 2日**。**市場の見立てと一致している。**
工数モデルは現実的で、直す必要は無い。

## 判断

### 賛成（イラスト・図解に寄せる）

破綻しない9本のほとんどがイラスト・CG・モーショングラフィックス。
サイトの9ジャンルのうち**「アニメーション・図解」がいちばん品質が安定する**。
ECLAT が実案件を取れているのもこの型。

### 反対（実写風を捨てない）

Soul ID で人物の一貫性は解ける。粗さの67%が「人物の一貫性」なら、
そこを解いた時点で**他社より優位に立つ**。
みんなが避けている領域だからこそ、やれれば差別化になる。
ただし**物理的な動き（81%）は Soul ID では解けない**。

### 第三の見方：客はそこまで見ていない

破綻を数えたのはAIの目であって、客の目ではない。
ECLAT の実案件（大阪労働局・病院・介護）は、**破綻の有無ではなく
「安く早く作れるか」**で選ばれている可能性が高い。
品質論に寄りすぎると、値段と納期で負ける。

### 推し

**イラスト・図解を「品質が保証できる型」として前に出す。
実写風は Soul ID で試すが、売り物にするのは持つと確認できてから。**

理由：破綻しない9本の実例が、そのまま再現手順になっている。
実写風は81%が物理で破綻しており、Soul ID でも解けない部分が残る。
**確実に納められる型から売る**ほうが、受注0本の段階では合理的。
